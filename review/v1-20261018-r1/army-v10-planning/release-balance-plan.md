# 1.0 개정 출시·밸런스 검증 계획
2026-10-18. 설계 전용. 제품 테스트·구현·출시·배포 승인을 뜻하지 않는다.

## 단계
1. 지도 불변식: 1,000 seeds×5장의 모든 경로 최소7전투, 보스 도달, 정예0 경로, 최대폭3/서비스2, 결정적 생성, 선택서비스가 전투를 건너뛰지 않는지 검사한다.
2. 저장: 진행 중 구2장 저장 불변, 새 버전 분리, 보상 대기/처리/각성 직전·직후/서비스 패스/전투 결과 재개를 실제 런타임에서 검사한다. 독립 fixture PASS와 제품 저장 PASS를 분리한다.
3. 경제: 34선택 후보안의 실제 적격 풀·보유19/20·유물 중복·포화 제련·지출 시점·목표 거절·상점 건너뛰기·궁극 미획득을 같은 seed로 비교한다. 모든 가격/회복/보상 조정은 미확정이다.
4. 전투: 병력5/7/9·예비0/1/2·궁극없음·열쇠미획득·회복/방벽없음 조합의 승률, 장별 컨디션, 기술별 출전/첫발동/횟수/피해/치유/보호막을 측정한다. 승률 기준과 표본 수는 구현 후 사전 등록한다. 지금은 UNKNOWN이다.
5. 시간·UI: 35전투 최소의 총시간, 노드 선택·보상·편성·재개 지연, 의미없는 중간 클릭 제거, 보스 사전 공개를 실기기에서 확인한다. 41.25~68.75분은 입력 가정으로 계산한 예시이지 출시 성능 목표가 아니다.

## 완료 금지 조건
전투 또는 저장 검증이 없으면 설계 검증 PASS를 제품 PASS로 표현하지 않는다. 비용 조정·34보상·XP 이관·휴식 회복량은 사용자 확정으로 표시하지 않는다. 기존2장 저장 변환/실서비스 변경/배포는 이 작업 범위 밖이다.

기존 상세검증안은 archive-20-battle에 보존되며 새 전투 수·보상 수·피로 계약과 충돌하는 항목은 적용하지 않는다.
