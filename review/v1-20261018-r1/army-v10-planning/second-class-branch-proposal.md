# 2차 전직 16갈래 비교 제안

작성: 2026-10-18 UTC. 상태: 탐색 설계, 채택·구현·출시 확정 아님.

사용자 요청: “2차전직도 아예 두갈래로 설계해보는건 어때 그냥 다른직업들도 같이”

## 1. 결론과 결정 경계

**4기본계열 → 8개 기존 1차 → 각 2갈래인 16개 2차 → 선택한 2차의 두 기술을 유지한 3차**가 장기 구조로 적합하다. 차이는 공격력 크기가 아니라 ‘무엇을 어떻게 해결하는가’로 만든다. 2차 분기와 기존 특화/운용 훈련은 독립 선택이다.

- 기존 `class-skill-progression.md`의 **2차 8종 + 훈련 운용 변형**은 더 작은 대안 A로 보존한다. 이 문서는 대안 B이며 기존 승인 또는 기준선을 조용히 덮어쓰지 않는다.
- 2차마다 **고유 기술 2개**, 3차는 **동일 2개 + 궁극 1개**다. 평범한 평타·플레이어 지휘·훈련 수치 패시브를 기술 슬롯으로 세지 않는다.
- 본 제안은 16개의 서로 다른 2차 직업 정의와 **32개 기술 슬롯 명세**를 요구한다. 기존 기술 계승이 있으므로 전부 신규 코드 32개라는 뜻은 아니지만, 기존 8직업안의 16슬롯보다 설명·행동·유물·저장·시각 검증 범위가 크게 늘어난다.
- 4계열 궁극 틀과 기존 열쇠 4개를 확장하는 안이다. **16개 전용 전설 열쇠·16종 별도 궁극 시스템을 만들지 않는다.** 16갈래의 유한 변환 명세·검증은 별도로 필요하다.
- 현재 창병 P0는 guardian의 성채수호병 후보 1개와 charger의 돌파선봉병 후보 1개를 다룬 격리 모듈이다. **창병의 2차 4갈래 완성, 16직업 완성, 제품 전투 통합 또는 배포가 아니다.** 본 문서는 해당 모듈을 바꾸지 않는다.
- 이름·효과·거리·상태 분류·선택 UI는 모두 후보다. 새 계수·초·비용·상태 저항률은 확정하지 않는다.

## 3. 두 기술의 실행 계약과 분기 차이

### 모든 직업 공통

- 기존 8종안에 있던 기술은 해당 계약을 출발점으로 유지한다. 새 기술도 candidate → commit → resolve → recovery를 정의하고, 합법 대상이 없으면 미발동, commit 뒤 실패면 정해진 비용과 재사용을 유지한다.
- 두 공격 기술·주문·지원 행동은 **같은 병사의 행동 예산**을 쓴다. 조준·반격·제압을 무료 동시 피해 트랙으로 더하지 않는다. 마법사는 기존 마나 풀 하나를 공유한다.
- 새로운 제어·정화·예방도 별도 주기와 시전/회복 시간을 가진 행동이다. 공짜 영구 오라로 바꾸지 않는다. 자동 발동 후보이며 16개 직업별 조작 메뉴·개별 버튼을 요구하지 않는다.
- 같은 대상/위협의 반복 잠금을 막는 상한과 갱신 제한이 필요하다. 최종 피해 감소 55% 등 기존 안전 상한을 우회하지 않는다. 상태 지속/공격 지연 신규 상한값은 아직 미정이다.
- 현재 위치로 판정하는 거리와 시작 배치로 판정하는 유물/연결을 구분한다. 이동했다고 시작 열 유물을 재발동하지 않는다.

### 창병 네 갈래

**성채수호병:** 방벽 연결은 기존 시작 상하좌우 인접 보호, 방벽 전개는 연결 대상 하나의 유한 피해 완화다. 연결 훈련은 계속 상시 연결에 유효하고 전개에 중복 적용하지 않는다. P0 수치 채택 여부는 기존 시험 문서에만 둔다.

**반격호위병:** 같은 방벽 연결을 유지한다. 반격 견제는 연결 아군에게 근접 공격을 유효하게 해결한 적이 자신의 짧은 창 사거리 안에 있을 때 후보가 된다. 준비 후 그 적에게 제한된 물리 타격과 짧은 이동 둔화를 주되, 다음 평타 슬롯을 소비하고 후딜을 지불한다. 대상이 이탈하면 추적 돌진하지 않는다. 피해를 되돌리거나 공격을 취소하는 무적 반격이 아니다. 근접 돌입을 견제하지만 이미 받은 강타를 복구하지 못한다. 연결 특화/운용 투자는 그대로 유지된다.

**돌파선봉병:** 기존 돌격 + 유효 돌격 뒤 자가 엄호. 현행 돌격은 실제 위치 이동·넉백·기절이 아니다. 이름이나 애니메이션 때문에 이동 기능이 있다고 설명하지 않는다.

**추격창기병:** 같은 돌격을 유지한다. 퇴로 봉쇄는 유효 돌격에 맞은 생존 적 중 후속 사거리 안 1명에게 별도 준비 후 짧은 이동 둔화를 준다. 자기 보호가 없고 후속 행동이 다음 돌격/평타를 늦춘다. 영구 속박·끌어오기·보스 고정 없음. 보스 이동 둔화에는 기존 절반 원칙을 준용하는 비교안이다. 기존 돌격 후 DEF 훈련은 남고 봉쇄를 통해 재발동하지 않는다.

### 궁수 네 갈래

**정밀사수:** 강화탄은 기존 유효 세 번째 사격의 평타 대체, 고정 조준은 합법 사거리 안 중요한 적을 잠그는 준비 행동이다. 사거리/강화탄 훈련을 보존한다.

**감시사수:** 같은 강화탄을 유지한다. 경계 사격은 공개 예고 중인 사거리·감시 영역 안 일반 적 1명에게 **다음 사격 예산을 예약**하는 행동이다. 유효한 예고 창에 명중하면 그 일반 행동을 제한적으로 지연한다. 보스 주요 패턴·페이즈 전환·이미 resolve한 공격은 취소하지 않는다. 감시 탄은 기존 다음 사격의 일반/강화 여부를 그대로 이어받으며 추가 탄·무료 카운터 진척이 없다. 적격 예고가 없으면 예약이 만료되고 정상 사격으로 복귀하나 대기 시간은 환불하지 않는다. 보스전에서는 강화탄과 일반 공격이 정상 작동하며, 감시 기술 무발동 비용이 과하면 후보를 재설계한다. 감시 AI가 숨은 미래 상태를 읽지 않는다.

**기동연사수:** 일제 사격은 주/보조 표적에 유한 예산을 나누고, 후퇴 기동은 통과 가능한 짧은 실제 경로에서 공격을 멈추고 거리를 벌린다. 안전 경로가 없으면 텔레포트하지 않는다.

**제압궁수:** 일제 사격을 유지한다. 견제 사선은 고정된 좁은 사격 영역에 유한 횟수의 견제 탄을 배분해 적의 이동을 잠시 늦춘다. 미래 평타 예산을 빌린 만큼 후속 사격 공백을 갚고, 별도 무료 DPS를 더하지 않는다. 영역 밖 적을 쫓거나 지휘처럼 적 전체를 정지시키지 않는다. 주/보조 배율·대상 수 훈련은 적격 사격에 유지하되 남는 보조 탄을 단일 보스에게 몰아주지 않는다. 기동형과 달리 근접한 적에게서 스스로 도망가지 못한다.

### 마법사 네 갈래

**화염전술사:** 폭염탄 + 잔불 지대. 두 주문이 마나를 경쟁하고 고정 지대의 실제 잔여 피해만 남는다.

**열막술사:** 폭염탄을 유지한다. 열기 장막은 사거리 안 작은 아군 영역에 짧은 **원거리 피해 완화 예산**을 설치한다. 투사체 물리 시뮬레이션·시야 차단을 요구하지 않는 초기안이며, resolve 때 적격 원거리 피해 태그와 수혜자의 영역 안 여부를 검사한다. 보스라고 자동 차단하지 않고 근접/지면 피해는 대상이 아니다. 한 시전자 한 영역, 가장 강한 완화 1개와 공통 감소 상한을 적용한다. 피해 반사·마나 회복 없음. 공격 주문을 줄여 방어 창을 사는 선택이므로 수호사의 모든 피해 보호막을 대체하지 않는다. 폭염탄 주 표적 계수·마나 비용 훈련은 그대로 살아 있다.

**한파조율사:** 서리 화살 + 냉기 경계. 새 진입을 늦추는 공간 제어이며 완전 빙결이 아니다.

**한기봉인사:** 서리 화살을 유지한다. 한기 봉인은 사거리 안 1명의 다음 **일반 공격 후 회복 구간**을 한 번 연장하는 주문이다. 준비 중인 공격 자체를 취소하지 않으며 보스 주요 패턴 시계는 바꾸지 않는다. 한 대상에 중첩·연쇄 갱신하지 않고 사용/기한 만료로 끝난다. 이미 적이 붙었을 때 다음 피해의 간격을 만드는 대신 범위 진입 억제를 포기한다. 공격 타이머와 상태 이벤트 신규 계약이 필요하므로 높은 난도다. 원래 서리 화살의 지속·비용 훈련과 유물은 유지하며 봉인에 자동 확대하지 않는다.

### 지원 네 갈래: 회복·해제·흡수·예방

**야전의무장:** 야전 진료는 기존 위급 대상 배율이 있는 정상 치유. 집중 수술은 실제 결손이 큰 생존 대상 1명을 긴 준비 뒤 크게 회복하는 특수 치유다. 수술 동안 정상 진료가 밀리므로 둘의 HPS를 단순 합산하지 않는다. 상태 해제는 없다.

**정화의무관:** 야전 진료를 동일 계승한다. 저주 정화는 사거리 안 살아 있는 아군의 **명시적으로 해제 가능한 부정 상태 하나**를 제거한다. 상태가 없으면 쓰지 않고 정상 진료를 계속한다. 정화 자체는 HP 회복·보호막·면역·마나 환급을 주지 않는다. 치유 감소가 걸린 위급 아군이라도 정화 준비 중 사망 가능성이 있으므로 공개된 긴급도/잔여 상태 시간을 비교한다. 진료와 정화를 동시에 하지 않는다. 정상 치유의 응급 배율 훈련은 그대로 남고, 사거리 훈련을 정화의 거리 원천으로 쓰는 안을 비교한다. 큰 수술 부재가 실제 기회비용이어야 한다.

**결계수호사:** 약한 정상 진료 + 총량을 나눠 지급하는 교대 방벽. 생명력 손실을 미리 흡수하지만 저주 부여를 자동 무효화하지 않는다. 이미 받은 큰 피해를 수술처럼 복구하지 않는다.

**금제수호사:** 약한 정상 진료 + 금제 방벽. 금제 방벽은 **한 번 시전되는 작은 피해 보호막에 부착된 유한 예방 효과**다. 같은 AP·보호막 훈련 산식에서 순수 방벽보다 작은 피해 예산을 사용하고, 유효 창에 들어오는 다음 적격 부정 상태 1회를 막으면 예방분은 소모된다. 이미 걸린 상태는 지우지 않는다. 보호막 잔량 소진/교체/만료/시전자 사망 시 남은 예방도 끝나는 초기안이다. 보호막 AP 계수와 지속 훈련을 그대로 이용하되 예방 횟수는 AP/지속과 함께 증가하지 않는다. 예방만 다시 채우려고 동량 보호막을 덮어씌우는 갱신 금지. 독립 예방 오라를 세 번째 기술로 숨기지 않는다.

금제 방벽은 저주 없는 적에게도 작은 피해 보호가 있지만 순수 교대 방벽보다 열등하다. 따라서 ‘큰 보호 + 모든 상태 면역’ 상위호환이 아니다. 반대로 예방 때문에 기존 보호막 투자·진료 유물이 사라지는 형태도 쓰지 않는다.

## 4. 3장 흑마법사와 상태 대응 제안

새 적·상태·수치는 **제안**이다. 3장에 다음 두 상태만 먼저 비교하고 독·침묵·공포·기절을 한꺼번에 추가하지 않는다.

- **회복 저주:** 일정 시간 받는 HP 치유량을 감소시킨다. 치유 완전 금지·컨디션 감소·원정 영구 손상 없음. 정상 치유와 특수 치유 모두 적용 여부를 명시하고 보호막은 HP 치유와 구분한다.
- **쇠약:** 일정 시간 나가는 공격 피해를 감소시킨다. HP/AP 원본 능력치를 바꾸지 않아 치유·보호량까지 숨게 깎지 않는다. 감소율·지속·동일 상태 재부여 제한은 미정이다.
- 상태 인스턴스에 원인·대상·부여/만료 시각·해제 가능 여부·예방 가능 여부를 기록한다. 동률 상태는 공개 우선순위와 안정 ID로 선택한다. 반복 부여는 더하기 대신 정해진 강도/갱신 상한을 따른다.
- 흑마법사는 대상과 저주 종류를 먼저 예고한다. 아이콘·텍스트·형태를 함께 쓰고 색상만으로 구분하지 않는다. 정화/예방 가능 여부도 보인다.
- 첫 등장에서는 한 종류를 소수 대상에게 사용한다. 연속 재부여·다중 저주로 전담 지원병을 강제하지 않는다. 전투 종료 뒤 상태를 원정 전체로 끌고 가지 않는 비교안이다.
- 적용 순서는 적격 상태 시도 → 유효 예방 판정/소모 → 실제 상태 부여 → 이후 별도 정화다. 예방은 저주 피해까지 자동 취소하지 않고, 정화는 이미 준 피해를 돌려주지 않는다. 같은 tick 순서는 안정된 이벤트 순서로 재현한다.

| 적이 던지는 질문 | 두 가지 이상 가능한 대응 | 강제하지 않을 것 |
|---|---|---|
| 회복 저주 뒤 강타 | 정화로 기존 저주 해제 / 예고를 보고 예방 / 미리 피해 보호막 / 시전자 집중 제거·지휘 방어로 지속 버티기 | 정화 1직업 없으면 회복 0, 필패 |
| 쇠약으로 화력 공백 | 상태 정화 / 예방 / 영향 없는 아군에 화력 분산 / 억제·방어로 만료까지 버티기 | 궁극·전설로만 해제 |
| 큰 단일 강타 | 성채 전개·피해 보호막 / 공격 전 표적 제거 / 생존 뒤 집중 수술·지휘 회복 | 수술만 생존 가능하도록 피해 역산 |
| 빠른 다수 접근 | 냉기 경계·견제 사선 / 기동 후퇴 / 두꺼운 전열·광역 화력 | 둔화 전용 열쇠 필수 |
| 원거리 집중 압박 | 열막·피해 방벽 / 정밀 제거·감시 / 배치 분산·전열 유지 | 열막 없으면 사거리 밖 적 무적 |
| 소수 공격자의 긴 교전 | 한기 봉인·정상 진료 / 빠른 제거·반격 / 보호 예산과 지휘 활용 | 봉인으로만 보스 패턴 중단 |

‘대응 2개 이상’은 설계 목표이지 완주 검증 결과가 아니다. 정화 0·예방 0·지원 0·궁극 0 대조군을 실제 조우에서 따로 검증한다. 지휘의 기존 회복이 저주를 해제한다고 설명하지 않는다.

3장 수집 → 4장 진입 선택적 각성 → 5장 활용은 유지한다. 각성 1명·0G·열쇠 비소비·자동 1회 등은 현행 P0 시험값이지 본 분기 제안으로 사용자 확정이 되는 것이 아니다.

## 6. 훈련·유물 호환과 저장

### 기존 투자 보존

- guardian 두 직업: 자신의 DEF와 연결 AP 계수 유지. 연결을 단순 신규 오라로 교체하지 않는다.
- charger 두 직업: 돌격 AP 계수·유효 돌격 뒤 DEF 유지. 봉쇄·궁극 파생이 훈련/돌격 칼집을 다시 발동시키지 않는다.
- sniper 두 직업: 강화탄 AP 계수·사거리 유지. 감시 탄의 원래 순번과 비치명 여부를 보존한다.
- volley 두 직업: 주/보조 표적 배율·대상 수 유지. 제압 사선의 예산에도 주/보조 구분을 명시하고 부족한 적의 탄을 집중하지 않는다.
- pyromancer 두 직업: 폭염탄 주 표적 계수·폭염탄 비용 유지. 열막이 모든 마나를 써 폭염탄 투자를 무효화하면 AI/비용/빈도를 수정한다.
- frostmage 두 직업: 서리 화살 지속·비용 유지. 봉인이 원래 서리 화살을 완전히 대체하지 않는다.
- medic 두 직업: 정상 진료의 위급 배율·치유 거리 유지. 정화에는 회복 배율을 적용하지 않는다.
- warder 두 직업: 보호막 AP 계수·지속 유지. 금제의 예방 횟수에는 곱하지 않는다.

### 이벤트별 호환

- 창 평타·궁 평타 유물: 적격 기본/강화 평타에만. 반격 견제는 별도 물리 `unit_skill` 후보, 돌격/주문/보호에는 평타 유물을 자동 확대하지 않는다.
- 저격 강화탄·강화 일제·감시의 강화 사격: 기존 비치명 및 한 번 적용 계약을 유지한다. 제압 사선 탄의 `enhanced_basic` 분류를 채택 전에 명세한다.
- 정상 치유 유물·진료 시계·응급 붕대함: 네 지원직의 정상 진료에만 기존 조건으로 적용. 수술·정화·예방·보호막은 정상 치유가 아니다.
- 보호막 유물/훈련: 교대/금제 방벽의 실제 피해 보호량에 적용. 예방 1회를 보호량처럼 증식하지 않는다.
- AP·계열·배치 유물: 기존 투영을 한 번 적용. 열막의 보호·정화의 상태 제거에 별도 AP 곱 보너스를 임의 추가하지 않는다.
- 잔향 수정: 적격 유료 주문 성공 1회 단위. 장막 틱·봉인 해소·궁극 변환은 새 유료 주문이 아니다. 무피해 영역 설치의 성공 정의는 기존 냉기 경계 계약을 참조해 정한다.
- 서리 고리: 명시된 서리 둔화만. 한기 봉인의 공격 회복 지연까지 자동 확장하지 않는다.
- 피해 완화형 방벽 전개/열막과 피해 흡수형 보호막은 다른 태그다. 이름이 비슷하다고 보호막 유물을 양쪽에 적용하지 않는다.
- 조건부 유물의 현재 보류 상태, 72후보·첫25 검증 범위는 유지한다. 16직업안 채택이 신규 유물 출시 승인이 아니다.

### 선택·저장 제안

기존 1차와 훈련 II를 충족하는 마지막 성장 거래에서 **둘 중 한 2차를 선택**하는 흐름을 비교한다. 별도 네 번째 성장 보상·추가 전직비를 자동 추가하지 않는다. 선택 패널이 하나 더 생겨도 보상은 한 건이다. 분기 선택 대기 상태는 저장되며 취소/재접속으로 보상 재추첨하지 않는다.

병사 ID·family·기존 branch ID·훈련 경로·컨디션·시작 배치를 유지하고 새 `secondClassId`를 추가하는 개념안이다. 훈련 두 경로를 새 2차 두 갈래로 재명명하지 않는다. 16직업 × 2훈련 경로가 각각 유효해야 한다. 구 저장은 이전 규칙 그대로 끝내며 새 원정 경계 밖에서 자동 변환하지 않는다. 재전직·무료 스킬 초기화는 요청 범위에 넣지 않는다.

## 7. 구현 범위·검증 게이트·진행 권장

### 대안 A: 기존 8직업 우선

장점: 기존 실행 계약과 창병 P0를 더 직접 활용한다. 단점: 1차 이후 직업 선택이 적고 ‘각 2갈래’ 경험은 제공하지 않는다. 16개 운용 변형을 16직업이라고 홍보하면 안 된다.

### 대안 B: 16직업 전부 동시 구현

장점: 일관된 전체 트리를 처음부터 제공한다. 단점: 32슬롯·16궁극 변환·상태 해제/예방·공격 타이머 제어·경로·영역·UI·저장·유물 조합 검증을 함께 늘린다. 현재 창병 모듈 결과만으로 일정이나 완성도를 보장할 수 없다. **권장하지 않는다.**

### 권장: 16직업을 목표 설계로 비교하되 대조 가능한 작은 묶음으로 검증

1. 기존 창병 P0를 비교 기준으로 고정한다. 실제 평타·피해 처리에 연결한 격리 호스트에서 현재 두 후보부터 검증한다. 이는 16갈래 승인과 별개의 이미 좁힌 작업이다.
2. 본 제안 채택 뒤에는 **guardian의 성채/반격 한 쌍**부터 비교하거나, 사용자 관심이 상태 대응에 있으면 **medic의 수술/정화 한 쌍 + 단일 흑마법사 상태 fixture**를 먼저 선택한다. 두 작업을 동시에 대형 확장하지 않는다.
3. 지원을 먼저 하면 예방형까지 한 번에 끝났다고 표시하지 않는다. warder의 순수 방벽/금제 쌍을 다음에 붙여 해제와 예방의 실전 차이를 검증한다. 회복 저주·쇠약 두 상태도 하나씩 도입한다.
4. 각 쌍은 같은 모집/훈련/유물 비용·같은 시드로 비교한다. 한쪽이 모든 적·편성에서 항상 유리하면 계수 조정보다 역할/기회비용을 수정한다.
5. 전 계열에 서로 다른 두 갈래가 실제 구현되기 전에는 완성 16직업 UI로 노출하지 않는다. 개발용 부분 트리는 지원 범위를 표시하고, 공개 도입은 승인과 제품 통합 검증 뒤 결정한다.

필수 검증:
- 16행 각각 기술 정확히 2개, 3차 동일 2개 + 1개. 평타/지휘 별도.
- 원래 8부모 × 2자식 × 2훈련 × 2차/3차 = **64 기본 계승 조합**에서 기존 투자 유효성. 이는 전체 유물/배치/적 조합 수가 아니다.
- 정상 진료 빈도·수술/정화 공백·방벽 실제 흡수·예방 성공/헛발동·상태 잔여 시간·과잉 치유·공격 빚·제어 가동률을 로그로 비교한다.
- 모든 적 질문에 최소 두 대응 경로. 정화 없음/예방 없음/열쇠 없음/궁극 없음/전설 없음 대조군. 특정 저주 보스 때문에 정화 직업을 의무 편성하지 않는다.
- 상태 제거 후 재부여, 동시 피해/예방/정화, 보호막 교체/만료, 시전자/대상 사망, 대상 없음, 범위 이탈, 일시정지/저장 재개, 중복 이벤트를 결정적으로 재현한다.
- 각 갈래의 실루엣·범위·상태 예고가 작은 모바일 화면에서도 구분되어야 한다. 16색만 바꾸는 방식은 불충분하다.
- 35전투 전체 완주·경제·피로·UI·저장 통합은 별도 게이트. 문서의 대응 경로나 모듈 단위 테스트만으로 통과를 주장하지 않는다.

이 문서 작성 외 제품 저장·코드·빌드·브랜치·PR·배포 변경은 하지 않았다. 다음 결정은 ‘16갈래 구조를 목표로 채택할지’와 ‘첫 비교를 창병 한 쌍/지원 한 쌍 중 어디로 할지’이며, 지금 당장 32슬롯 전체 제작을 약속하는 선택이 아니다.
