# 1.0 장별 시드 분기 지도 · 현행 설계
2026-10-18. 설계 및 독립 Python 검증기만 수정. 게임·운영 저장·배포는 변경하지 않았다.

## 확정과 명시적 해석
- 사용자 확정: 5장, 장당 최소 7전투 이상, 불필요한 중간 휴식 공간 제거, 랜덤 맵 시드와 슬레이 더 스파이어처럼 간략한 중간 갈림길.
- **보스를 최소 7판에 포함**하는 것은 이번 설계의 명시적 해석이다. 따라서 모든 적법한 완주 경로가 장당 일반/정예 6 + 보스 1, 전체 최소 35전투를 갖는다. 사용자가 일반전만 7판을 뜻했다면 8전투/장 이상으로 조정한다.
- 3장 유물 수집 → 4장 궁극 진입 → 5장 활용. 2차 고유 기술 2개, 3차 기존 2개 + 궁극 1개. 평타·지휘 버튼은 따로 센다.
- 구 20전투 문법과 합류 유지 권고는 폐기했다. 보관본은 archive-20-battle에 있다.

## 노드 문법 및 범위
기본 생성안은 전투층 1~6 → 보스층 7. 각 전투층은 2~3칸으로 폭을 제한하고, 보스는 하나다. 전투/정예 아이콘·서비스 아이콘·가는 연결선만 표시한다. 시작하자마자 보스 종류·핵심 위험을 공개한다. 장 입장과 합류는 별도 완료 노드·대기·클릭 화면이 아니다. 전투 보상은 전투 결과 패널에서 처리한다.

각 층 전투를 하나 끝내야 다음 전투층에 접근한다. 선택 서비스는 2·4층 전투 뒤에만 최대 하나씩 들르는 **덧붙임 분기**이고, 같은 다음 전투층으로 돌아간다. 무료 직행선도 항상 제공한다. 서비스·상점·휴식이 전투를 대신하거나 층을 건너뛰지 않는다. 모든 경로 7전투, 방문 서비스 0~2개/장. 지도 전체 후보는 6×3+1+2=최대21개/장이다. 추가 전투를 넣는 후속 생성기는 최소 불변식을 유지하며 별도 버전을 쓴다.

상점·사건·대장간·실제 회복 선택이 있는 휴식만 서비스 후보로 둔다. 강제 보스 전 야영·빈 합류·다음 버튼만 있는 중간 방은 제거한다. 휴식은 피로 회복이라는 실제 선택이 있는 경우만 남기며, 무료 직행과 다른 기회 비용을 미리 보여준다. 서비스 방문·패스 자체는 XP나 숨은 자동 회복을 주지 않는다. 예비 회복은 전투 완료 기준으로만 처리한다.

## 시드 생성 계약
- 생성기 버전, 규칙 버전, 정규화된 seed, 장 번호를 고정한다. 검증기는 SHA-256 기반 결정적 선택을 써 실행 순서·Python 난수 구현에 의존하지 않는다.
- 각 층 lane 0은 일반전으로 유지하며 lane 0→0 연결은 항상 보장해 정예 0회 경로를 둔다. 다른 노드는 일반/정예이며 전투 위험은 사전 공개한다.
- 인접층에서 가까운 lane끼리 연결하고 필요한 가장 가까운 연결을 추가해 모든 노드에 진입과 보스까지의 출구가 있도록 한다. 서비스 분기는 같은 다음 전투층의 도달 가능한 후보로만 연결한다.
- 생성기는 최대 폭3·서비스2·보스1, 전방 간선만 허용한다. 막다른 길·고아·순환·보스 우회·전투층 건너뛰기를 거부한다. 실제 전투 콘텐츠 RNG와 지도 RNG는 분리해야 한다.
- 시작 시 지도 전체를 생성·저장하고 동일 seed 재접속으로 지도·상점 재고·목표를 다시 뽑지 않는다. 저장에는 generatorVersion, rulesVersion, seed, chapter, graphHash, 완료 경로, 보상 처리 원장을 둔다. seed만 저장하고 최신 생성기로 재생성하지 않는다.
- 검증기 저장 fixture는 생성기 버전·지도 해시·실제 간선에 따른 경로·중복 완료·XP 누계를 검사한다. 제품에서는 전투 결과/보상 대기/각성 선택 상태도 별도 검증해야 한다. 알 수 없는 버전은 조용히 교체하지 않고 지원 실패로 처리한다.

## 장별 내용 배치
1장: 전투1 편성 읽기, 2 진화 선택, 3~4 1차 체험, 5 훈련 I 기회, 6 보스 문제 예행, 7 보스. 2·5의 성장 기회는 대상 자격/선택이 맞을 때만 진전한다.
2장: 전투1 훈련 II/2차 기회, 2~6 두 고유 기술의 다른 대상·타이밍을 사용하는 조우, 7 보스. 1차·훈련 I·II 세 성장 선택안을 유지하되 사용자 미확정이다.
3장: 6전투와 보스의 혼합 보상 기회로 유물 수집. 전투2 이후 선택 상점에 목표 열쇠 재고를 제안하고, 정예를 택하지 않아도 보스 보상에서 미획득 목표 한 슬롯을 선택할 수 있게 한다. 선택 기회 보장이지 자동 지급은 아니다. 상점·정예 건너뛰어도 진행 가능하다.
4장: 장 진입 지도 패널에서 조건 충족자의 선택적 각성. 별도 합류/휴식 방 없이 실행한다. 궁극 미선택도 진행하며 전투1~7은 궁극의 사용 기회이지 발동 보장이 아니다.
5장: 완성 빌드로 7전투. 최종 보스는 정산만 하고 더 사용할 수 없는 성장 보상 창은 열지 않는다.

## 제거 노드 XP 보상 이관안 (미확정 수치)
기존 4전투+4서비스+2합류=장당 XP10에서, 합류만 제거하면 XP2/장, 서비스 전체를 무보상화하면 추가 XP4/장이 사라진다. 따라서 무보정 삭제는 하지 않는다.

새 전투1~7 XP 증분을 **3, 1, 1, 1, 1, 2, 1**로 제안한다. 장당10·5장50을 보존하며 선택 서비스는 XP0이다. 최초 승리 처리와 XP 이관을 하나의 멱등 트랜잭션으로 기록한다. XP==완료노드수라는 옛 저장식은 새 버전에서 사용하지 않는다.

XP 임계0/4/9/13 → 출전6/7/8/9 유지. 7명은 1장 전투2 뒤(전투3부터), 8명은 1장 전투6 뒤(보스부터), 9명은 2장 전투1 뒤(전투2부터)다. 구안의 실질 배치 가능 시점인 작전3/1장보스/2장작전2와 대응한다. 새로 추가된 중간 전투 때문에 분 단위 해금 시점까지 같다는 뜻은 아니다. 전투7회에 무조건 XP1만 주는 대안은 총XP35와 초반 해금 지연이 생겨 채택하지 않았다. 병사가 자동 모집되는 것은 아니다.

## 검증 범위
독립 검증기는 모든 경로의 전투 수를 DAG 최소/최대 경로 계산으로 확인한다. 무작위 경로 몇 개만 지나서 전 경로를 보장한다고 하지 않는다. 1,000 seeds×5장에 재현성·도달성·폭·서비스수·정예0회·XP·저장 오류 검사를 수행한다. 실제 전투 승률·피로 균형·소수 병력 완주·시간·기술 발동은 미검증이다.

## 유물 획득·검증의 연결 계약

유물 후보72종은 보존하되 첫 검증25종(기존17+열쇠18~21+배치26~29), 조건부 다음11종, 후속36종으로 구분한다. 34보상 기회는 유물34개가 아니다. 카테고리→희귀도→적격ID→사전 고정 fallback 순서와 동일 선택 예산을 지키며, 편성 조작/중복/포화로 카테고리를 다시 추첨하지 않는다. 실효 증가·대가·의미 있는 조건·남은 이용처·각성 자격은 [대도감 §3·§8](relic-catalog.md)의 공통 preview/획득 계약을 따른다. 가중치·fallback 가치·가격·XP 배분은 미확정 제안이며 문서 개정은 제품 구현/전투 검증 승인이 아니다.
