# 꼬마 군단 원정대 1.0: 병과·기술 성장 설계

작성: 2026-10-18 UTC  
상태: 요청받은 로컬 사전 설계. 이 문서는 제품 코드·빌드·배포를 변경하지 않는다. 신규 직업명·기술명·발동 방식·전직 자격과 효과는 제안이며, 신규 계수·초 단위·최종 밸런스는 확정하지 않는다.  
기준: `content-plan.md`, `five-chapter-run.md`, 실제 `tiny-army-sites/dist/js/v09-content.js`. 장 구성은 최신 5장 설계를 우선한다.

## 1. 먼저 고정하는 구조

### 사용자 확정

- 한 플레이는 **5장**이다. **3장 유물 수집 → 4장 궁극 진입 → 5장 활용** 순서를 지킨다.
- **2차 전직 = 고유 기본 기술 2개. 3차 전직 = 그 2개 유지 + 궁극기 1개.** 평범한 자동 공격은 기술 수에 넣지 않는다.
- 병사 고유 기술과 플레이어 지휘 기술은 서로 다른 체계다. 병사에게 기술이 생겨도 현행 지휘 기술 장착 2칸을 차지하지 않는다.

### 유지하는 제약

- 기존 4기본계열과 8개의 **1차 진화**를 없애거나 2차로 조용히 재명명하지 않는다.
- 각 1차 역할에 대응하는 2차 전문 직업 1개씩, **2차 8종**을 제안한다. 각 직업 안의 특화/운용 훈련은 **16개 운용 변형**이지, 16개의 추가 직업이나 기술 슬롯이 아니다.
- 2차는 특정 열쇠 없이 기술 2개가 모두 작동하는 완성 빌드다. 궁극이 없어도 일반 난도 5장 완주가 가능해야 한다.
- 선택적 3차만 해당 계열 열쇠 유물을 요구한다. 4계열 궁극 틀을 공유하되 방벽/돌격, 저격/연사, 폭염/서리, 치유/보호막의 동사를 지우지 않는다.
- 병사 ID·계열·훈련 투자·컨디션·배치·기존 유물 적용 경로를 이어 간다. 3차를 다른 병사로 교환하거나 시너지 인원을 추가하지 않는다.

### 아직 확정하지 않는 것

- 2차 자격을 기존 훈련 II와 묶는 방식, 아래 가칭, 개별 신기술의 최종 구현 범위.
- 기본 기술 자동 발동과 궁극 자동/수동 방식, 전투당 궁극 횟수·충전 방식.
- 열쇠 I 인정·비소비, 원정당 각성 1명·추가 각성비 0G는 기존 문서와 맞춘 **초기 비교안**이다.
- 공격·회복 계수, 쿨다운, 자원 소모, 사거리 증가량, 범위, 보호량, 기술 간 회복 시간. 아래의 '짧음/긴 주기/제한됨'은 조율 방향이지 완성 수치가 아니다.

## 2. 현행에서 실제로 이어지는 계보

| 기본 병과 | 현행 1차 진화 / ID | 제안 2차 직업 | 두 기본 기술의 역할 | 3차 궁극 계열 |
|---|---|---|---|---|
| 창병 `spear` | 방벽병 `guardian` | 성채수호병 | 연결 유지 + 필요한 순간 방벽 전개 | 불굴의 선봉 · 수성형 |
| 창병 `spear` | 돌격병 `charger` | 돌파선봉병 | 돌격 + 돌격 뒤 자가 엄호 | 불굴의 선봉 · 돌파형 |
| 궁수 `archer` | 저격수 `sniper` | 정밀사수 | 강화탄 + 제한적인 고정 조준 | 천공의 명수 · 일점형 |
| 궁수 `archer` | 연사수 `volley` | 기동연사수 | 일제 사격 + 공격을 쉬는 후퇴 기동 | 천공의 명수 · 탄막형 |
| 마법사 `mage` | 폭염술사 `pyromancer` | 화염전술사 | 순간 폭염 + 일정 지역의 잔불 | 비전의 현자 · 홍련형 |
| 마법사 `mage` | 서리술사 `frostmage` | 한파조율사 | 단일 둔화 + 진입 경계 형성 | 비전의 현자 · 한파형 |
| 지원병 `support` | 군의관 `medic` | 야전의무장 | 반복 진료 + 긴 주기의 집중 수술 | 생명의 수호자 · 구명형 |
| 지원병 `support` | 수호사 `warder` | 결계수호사 | 약한 반복 진료 + 시차를 둔 보호막 | 생명의 수호자 · 방호형 |

**단계 표기 예:** 창병 → 방벽병(1차) → 성채수호병(2차, 특화/운용 중 선택한 경로) → 불굴의 선봉·수성형(3차). 3차 카드에서도 '성채수호병 계승'과 두 기본 기술을 남긴다. 외형·초상화를 재사용할 수 있다는 것과 전직 단계를 생략한다는 것은 다르다.

### 코드 사실과 신규 설계를 구분한다

- 현행 방벽병은 인접 보호, 돌격병은 돌격, 저격수는 매 세 번째 강화탄을 갖는다.
- **현행 연사수는 다중 평타가 중심이며, 독립 고유 기술 2개가 구현돼 있지 않다.** 다중 평타를 이름만 바꿔 두 기술로 세면 안 된다.
- 현행 폭염/서리는 각각 주문 1개를 쓴다. 두 번째 주문은 새 설계·검증 범위다.
- 현행 군의관의 위급 대상 치유 배율은 정상 치유의 조건부 효과다. 이를 정상 치유와 별개 기술 1개로 중복 계산하지 않는다.
- 현행 수호사는 치유와 보호막 두 행동이 이미 있다. 2차에서는 이 두 계열을 유지하되 보호막의 시차·재선정으로 운영이 달라져야 한다. 이름 변경만을 신규 기술 2개 제작으로 보고하지 않는다.
- 저격 강화탄은 현행 이벤트 분류상 강화된 `basic_attack`이다. 별도 주기·고유 계수·비치명 규칙이 있는 **고유 기술**로 표시하되 평범한 평타와 분리한다. 표시 슬롯 수와 피해 이벤트 태그는 같은 개념이 아니다.

## 3. 5장 안의 성장 연결

| 장 | 병과 기술 측면의 경험 | 배치 원칙 |
|---|---|---|
| 1장 | 기본 계열을 알고 기존 1차 갈래를 선택 | 두 기술을 한꺼번에 설명하지 않고 핵심 역할을 먼저 체험 |
| 2장 | 2차에서 기본 기술 2개를 완성·운용 | 훈련 II 자격 통합을 제안하되 'II를 찍었다'만으로 실제 두 기술 명세를 생략하지 않음 |
| 3장 | 두 기본 기술에 맞는 유물 조합 수집, 원하는 계열 열쇠 탐색 | 열쇠 미획득·거절이어도 이미 선택한 2차가 정상 작동 |
| 4장 | 선택한 병사에 3차·궁극 1개 추가, 충분한 실전 시험 | 장 진입 지도 패널의 선택적 각성 기회안과 연결. 별도 합류 재기회는 없음. 4장 보스 뒤에야 주지 않음 |
| 5장 | 두 기본 기술·궁극·훈련·유물·교대를 함께 활용 | 새 필수 전직이나 '진짜 최종 기술'을 또 잠그지 않음 |

2차와 훈련 II를 묶는 비교 기본안에서는 **1차 진화 + 훈련 I + 훈련 II의 성장 3선택**으로 완성한다. 마지막 자격을 충족하는 선택의 같은 거래에서 2차 단계와 실제 기본 기술 2개를 함께 개방하고 전직 결과를 보여 준다. 별도 네 번째 보상 선택이나 추가 전직 골드는 없다. 기본 병과에서 먼저 II를 얻었다면 1차 선택이 마지막 조건이 되어 같은 규칙을 따른다. 전직 단계는 저장·표시에 별도로 남기므로 비용 간소화가 1차/2차 단계 삭제를 뜻하지 않는다. 기본 → 3차를 뛰거나 기존 훈련을 다시 사게 하지 않는다. 별도 유료 전직은 이 기본안에 섞지 않는 별도 비교 후보이며 재승인 전에는 적용하지 않는다.

2장의 초기 목표는 **주력 1명의 2차 체험**이다. 군단 전원이 2차로 완성된다고 가정하지 않는다. 나머지 병사의 모집·진화·훈련은 같은 보상/골드 예산에서 경쟁한다.

## 4. 모든 기본 기술에 적용하는 전투 계약

1. **기술은 행동이어야 한다.** 이름, 발동 조건, 대상 규칙, 유효 거리, 효과, 비용/주기, 실패 처리, 유물 태그가 있어야 한다. 공격력 +몇 % 같은 상시 수치만 별도 기술 슬롯으로 세지 않는다. 상시 연결처럼 지속적으로 대상을 계산하는 보호 행동은 기술이 될 수 있다.
2. **행동 예산은 공유한다.** 새 공격 기술은 무료 동시 공격 트랙을 더하는 것이 아니라 평타 슬롯 대체·시전 중 공격 정지·공유 마나·시전 후 회복 시간 중 적절한 비용을 가진다. 기술 2개라는 이유로 기존 DPS가 자동으로 두 배가 되어서는 안 된다.
3. 동시에 준비된 행동의 우선순위를 정한다. 예: 유효한 구조/자가 엄호 → 예약된 고유 기술 → 평타. 다만 지속 보호 연결은 계속 계산하고, 모든 병과에 같은 우선순위를 기계적으로 강제하지 않는다.
4. 쿨다운·마나·상태에 '대상 없음'을 구분한다. 발동 직전 합법 대상이 없으면 기다린다. 자원을 지불하고 발동 확정된 뒤 대상이 사망/이탈하면, 각 기술의 제한된 재선정 규칙만 적용하고 무제한 환불·재시전을 하지 않는다.
5. 거리와 대상은 기술 설명에 명시한다. '가장 위험한 적'이 화면 밖·무한 사거리 자동 저격을 뜻하지 않는다. 표적 동률은 안정된 기준으로 해소하고 불러오기·일시정지로 바뀌지 않는다.
6. 마법 기술 2개는 **기존 병사 1명의 마나 풀**을 공유한다. 두 번째 최대 마나·별도 무료 충전·일반 주문 쿨다운 초기화는 추가하지 않는다. 장판의 매 틱을 새 유료 주문으로 세지 않는다.
7. 치유는 살아 있는, 실제 HP가 부족한 대상에게만 유효하다. 0치유·초과회복·부활·컨디션 회복을 만들지 않는다. 보호막과 치유는 다른 이벤트다.
8. 기술 사용 중 전투불능·예비는 발동하지 않는다. 예비를 이용한 전투 중 궁극 충전·시너지·지원 효과는 없다. 교대는 기존 준비 화면에서 한다.

## 5. 2차 직업별 두 기본 기술

기술명은 가칭이다. 아래에서 '유지'는 현행 역할과 태그의 계승, '신규/재설계'는 1.0에 실제 행동을 추가하거나 바꿔야 한다는 뜻이다. 기술별 신규 수치는 모두 별도 비교 후 정한다.

### 5.1 성채수호병: 연결하고, 필요한 순간 막는다

| 항목 | 기본 기술 1: 방벽 연결 | 기본 기술 2: 방벽 전개 |
|---|---|---|
| 기반 | 현행 `guardian_link` 계승 | 신규 조건부 보호 행동 |
| 발동 | 살아 있는 출전 병사의 시작 배치를 기준으로 연결 유지 | 연결 대상 중 HP가 낮거나 예고된 공격 대상인 아군이 생기면, 자체 재사용 조건을 만족할 때 자동 후보 |
| 대상·범위 | 시작 격자 상하좌우 인접 아군, 방벽 계열 상호 연결 제외 | 기존 연결 대상 중 1명. 연결 범위를 군단 전체로 확대하지 않음 |
| 효과 | AP 기반 방어 제공, 현행 연결 상한 유지 | 짧은 보호 태세. 제한된 첫 유효 피해를 완화하고 종료; 무적·피해 전가·부활 아님 |
| 주기·비용 | 지속 연결, 시전자 생존 필요 | 긴 주기, 짧은 유효 창. 헛발동은 시간이 지나 사라지며 남은 방어를 저축하지 않음 |
| 태그 | 계열 `spear`, `passive_protection`, 연결 | `unit_skill`, 보호, 최종 피해 감소. 치유·보호막 태그를 자동 부여하지 않음 |

- 특화는 자신의 생존과 연결 유지, 운용은 연결 AP 계수를 통해 아군 보호가 강해진다. 둘 다 기본 기술 2개를 갖는다.
- 방벽 2명이 같은 아군을 보호해도 연결은 가장 강한 유효 1개만 적용한다. 방벽 전개도 같은 종류를 중첩해 피해 감소 상한을 우회하지 않는다.
- 강점은 소수 전열 유지, 약점은 분산 동시 피해와 시전자 전투불능이다. 연결 자체를 전맵 오라로 만드는 궁극은 쓰지 않는다.

### 5.2 돌파선봉병: 파고들고, 노출된 순간을 버틴다

| 항목 | 기본 기술 1: 돌격 | 기본 기술 2: 돌파 후 엄호 |
|---|---|---|
| 기반 | 현행 `charge` 계승 | 신규 피격 대응. 현행 운용 훈련의 DEF 증가를 단순 재명명하지 않음 |
| 발동 | 합법 표적이 돌격 거리 안에 있고 재사용 가능 | 돌격이 유효하게 해결되면 잠깐 준비되고, 그 창 안의 첫 유효 피격에 반응 |
| 대상·범위 | 거리·반경 안 적. 기존 넉백/기절 기능이 있다고 가정하지 않음 | 자신만 |
| 효과 | 준비 동작 후 물리 돌격 피해 | 돌격 직후의 한 번 피해를 제한적으로 완화. 방어 증가 훈련과 별도로 명시되는 짧은 대응 |
| 주기·비용 | 기존 비치명 고유 공격, 전후 행동 시간 점유 | 돌격에 종속되고 별도 내부 재사용으로 연속 충전 금지. 엄호 준비/회복 동안 다음 공격 일부 지연을 비교 |
| 태그 | `unit_skill`, 물리, 돌격 | `unit_skill`, 자가 보호, 최종 피해 감소. 방어력 상승 자체와 구분 |

- 특화 훈련은 돌격 AP 계수, 운용 훈련은 돌격 후 DEF를 계속 담당한다. 새 엄호가 운용의 DEF를 대체하거나 기본 지급해서 운용을 무의미하게 만들지 않는다.
- 새 피해 감소와 기존 DEF가 지나치게 겹치면 엄호량부터 줄이고 타이밍 보완을 남긴다. 고유 DPS·생존력 모두를 동시에 크게 올리는 설계는 피한다.
- 강점은 선제 압박 뒤 짧은 안전 창, 약점은 돌격 공백과 여러 적의 연속 타격이다. 상대를 끝없이 밀거나 보스를 경직시키지 않는다.

### 5.3 정밀사수: 한 발을 준비하고, 쏴야 할 대상을 놓치지 않는다

| 항목 | 기본 기술 1: 강화탄 | 기본 기술 2: 고정 조준 |
|---|---|---|
| 기반 | 현행 `precision_shot` 계승 | 신규 유한 조준 상태 |
| 발동 | 현행처럼 정해진 유효 사격 주기에서 평타를 강화탄으로 교체 | 다음 유효 사격이 강화탄 차례이고, 재사용 가능하며 합법적인 고가치 표적이 있을 때 조준 준비 |
| 대상·범위 | 유효 사거리 안 1명 | 표시된 한정 조준 사거리 안 1명. 조준 사거리는 기본·훈련·유물 사거리에 명시된 한도만 더함 |
| 효과 | ATK/AP 기반 단일 강화 사격, 비치명 유지 | 다음 강화탄의 대상 우선순위를 잠그고 제한적으로 사선을 확보. 추가 탄·추가 피해 배율을 기본 제공하지 않음 |
| 주기·비용 | 강화탄은 추가 공격이 아니라 예정된 평타 대체 | 준비 중 이동하지 않고 사격을 잠깐 지연. 유효 시간이 끝나면 잠금 해제 |
| 태그 | `basic_attack` + `enhanced_basic`, 치명 제외 | `unit_skill`, 조준/대상 선택. 자체 피해 이벤트 없음 |

- 관측 대상이 사망하거나 새 유효 거리 밖으로 나가면 명시된 규칙대로 조준을 풀거나 새 합법 대상 1명을 고른다. 남은 강화탄을 즉시 연속 발사하지 않는다.
- 조준이 강화탄 카운터를 임의로 채우거나 초기화하지 않는다. 조준 준비 때문에 카운터를 진행시킬 평타까지 무기한 멈추는 교착을 만들지 않는다.
- 특화 훈련의 강화탄 AP 계수와 운용의 장거리 사거리를 모두 유지한다. 고정 조준의 사거리 보너스가 운용 훈련보다 항상 우월해지지 않게 예산을 제한한다.
- 강점은 큰 한 대상의 정확한 제거, 약점은 긴 준비 시간·다수의 작은 적·이동 필요 상황이다. 고정 조준은 단순 수치 패시브가 아니라 준비→대상 잠금→한정 발사 기회의 실제 상태 전환으로 구현돼야 한다.

### 5.4 기동연사수: 넓게 쏘고, 거리를 다시 만든다

| 항목 | 기본 기술 1: 일제 사격 | 기본 기술 2: 후퇴 기동 |
|---|---|---|
| 기반 | 신규 유한 사격 행동. 현행 다중 평타 특성은 별도로 유지 | 신규 위치 행동 |
| 발동 | 여러 합법 적이 사격 범위에 있고 재사용 가능 | 적이 정해진 근접 위험 거리 안에 들어오고 안전한 이동점이 있을 때 |
| 대상·범위 | 사거리 내 서로 다른 적에 유한한 사격 묶음 | 자기 위치에서 짧은 실제 이동 경로, 맵 내부·통과 가능 위치만 |
| 효과 | 다음 평타 묶음의 일부를 짧은 시간에 배분. 같은 탄/보조탄을 단일 적에게 몰아주지 않음 | 짧게 물러나 거리 확보. 공격 정지, 무적·피해 무시·텔레포트 없음 |
| 주기·비용 | 사격 뒤 회복 시간을 지불해 이후 평타를 늦춤. 예정 공격 예산을 당기는 방식부터 시험 | 긴 내부 재사용, 이동 중 사격하지 않음. 안전한 지점이 없으면 제자리 공격 유지 |
| 태그 | `basic_attack` + `enhanced_basic`, 다중 사격, 주/보조 표적 분리, 비치명 초기안 | `unit_skill`, 이동. 이동속도 상한 준수 |

- 현행 주 표적 명중 훈련과 확산 사격 훈련은 평타·일제 사격의 적격 주/보조 탄에 이어진다. 부족한 표적의 남은 탄을 주 표적에 재배분하지 않는다.
- 훈련/유물이 대상수를 늘려도 '대상수 × 발사 묶음 × 무료 발동'으로 DPS가 곱해지지 않는다. 총 공격 예산과 사격 후 공백을 함께 비교한다.
- 강점은 잔병 처리와 제한적 거리 회복, 약점은 단일 보스와 후퇴 공간이 없는 상황이다. 무한 카이팅을 금지하고 맵 가장자리 반복 왕복을 검증한다.
- 경로 탐색 구현 비용이 지나치면 후퇴 기동을 순간이동으로 대체하지 않는다. 대안은 **공격을 쉬는 짧은 자가 방어 태세**이며, 별도 승인 후 한 안만 채택한다.

### 5.5 화염전술사: 한 번 터뜨리고, 남은 불길로 압박한다

| 항목 | 기본 기술 1: 폭염탄 | 기본 기술 2: 잔불 지대 |
|---|---|---|
| 기반 | 현행 `flame_burst` 계승 | 신규 유한 지속 피해 주문 |
| 발동 | 적격 표적·마나·재사용을 충족 | 여러 적이 머무는 유효 영역이 있고 공용 마나·재사용을 충족 |
| 대상·범위 | 주 표적과 제한 반경의 보조 표적 | 시전 시 정한 작은 지면 영역. 적이 벗어나면 추적하지 않음 |
| 효과 | 주/보조 계수가 다른 순간 광역 피해 | 짧은 시간에 나눠 주는 제한된 총 피해. 같은 시전자의 지대는 중복 설치하지 않음 |
| 주기·비용 | 공용 마나, 시전 시간 점유 | 공용 마나·독립 재사용·시전 시간. 다음 폭염탄을 늦출 수 있음 |
| 태그 | `unit_skill`, 마법, 유료 주문, 직접 피해 | `unit_skill`, 마법, 유료 주문, 지속 피해. 매 틱은 새 주문/평타/치명이 아님 |

- 특화의 중심 폭발은 폭염탄 주 표적에 유지한다. 운용의 연소 효율도 원래 폭염탄 비용에 유지하며 두 번째 주문까지 무조건 같은 비용으로 만들지 않는다.
- 잔불을 쓰면 순간 폭염 횟수가 줄 수 있다. 두 주문을 모두 '준비되면 즉시' 써 마나를 말리는 AI 대신 마나 여유·적의 체류 가능성을 조건으로 삼는다.
- 강점은 밀집·정지한 적, 약점은 분산·빠른 이동·긴 마나 공백이다. 새 잔불은 후속 후보 유물 `fire_mark`의 무료 복제물이 아니다. 장판과 표적 낙인의 이벤트·중첩을 따로 정의한다.

### 5.6 한파조율사: 한 적의 진입을 늦추고, 다음 길목을 준비한다

| 항목 | 기본 기술 1: 서리 화살 | 기본 기술 2: 냉기 경계 |
|---|---|---|
| 기반 | 현행 `frost_bolt` 계승 | 신규 지면 제어 주문 |
| 발동 | 적격 표적·마나·재사용 충족 | 적의 접근 경로에 유효 배치점이 있고 공용 마나·재사용 충족 |

| 효과 | 마법 피해 + 짧은 둔화 | 최초 진입한 적에게 짧은 둔화. 기본안은 별도 피해 없음 |

- 두 둔화는 강도를 합하거나 지속시간을 연속 더하지 않는다. 강한 1개만 적용하고 갱신에도 명시된 종료 상한을 둔다. 보스는 현행의 둔화 강도 절반 원칙을 유지한다.
- 특화의 서리 유지와 운용의 서리 화살 마나 절약은 기존 기술에 남는다. 경계가 서리 화살보다 모든 상황에서 싸고 오래가는 대체재가 되어서는 안 된다.
- 강점은 접근 지연, 약점은 이미 붙은 적·원거리 압박·경계를 우회하는 분산이다. 얼림·보스 행동 취소·영구 둔화를 새 기본 권리로 주지 않는다.

### 5.7 야전의무장: 평소에는 반복 진료, 위급할 때는 시간을 들여 구조

| 항목 | 기본 기술 1: 야전 진료 | 기본 기술 2: 집중 수술 |
|---|---|---|
| 기반 | 현행 정상 치유·위급 대상 배율 계승 | 신규 긴 주기의 구조 치유 |
| 발동 | 주기 도래, 살아 있고 HP가 부족한 대상 존재 | HP가 임계 이하인 합법 대상이 있고 재사용 가능 |
| 대상·범위 | 치유 사거리 안 낮은 HP 비율 우선 1명 | 치유 사거리 안 위급 대상 1명, 동률은 안정된 우선순위 |
| 효과 | AP 기반 정상 치유, 기존 응급 배율 적용 | 더 긴 준비를 지불하는 집중 치유. 지속적인 전군 회복 아님 |
| 주기·비용 | 기존 반복 치유 간격 | 수술 동안 평타·정상 치유를 쉬고, 종료 후 회복 시간을 지불. 지휘 응급 회복을 자동 복제하지 않음 |
| 태그 | `normal_heal`, 지원 정상 치유 | `unit_skill`, `special_heal`, 지원 구조 치유. `normal_heal`과 구별 |

- 두 기술의 평균 HPS를 그대로 합쳐 두 배로 만들지 않는다. 수술이 정상 치유를 얼마나 미루는지, 준비 중 대상 사망 위험이 있는지 비교한다.
- 특화의 위급 진료 배율은 정상 치유에 유지한다. 운용의 치유 사거리는 두 치유 행동의 기본 거리 원천으로 쓰는 안이다. 수술 고유 계수와 응급 배율의 곱셈 적용 여부는 자동 추정하지 않고 명시한다. 초기안은 **수술에 응급 배율 중복 적용 없음**이다.
- 정상 치유 전용 유물은 정상 진료에 계속 유효하다. 수술이 정상 치유를 거의 없애 유물을 죽인다면 수술 주기/조건을 좁힌다.
- 강점은 생존 아군 구조, 약점은 급작스러운 사망과 다수 동시 중상이다. 사망자 구조·초과회복 보호막 전환은 넣지 않는다.

### 5.8 결계수호사: 빈 체력을 조금 채우고, 피해가 오기 전에 보호를 나눠 둔다

| 항목 | 기본 기술 1: 수호 진료 | 기본 기술 2: 교대 방벽 |
|---|---|---|
| 기반 | 현행 약한 정상 치유 계승 | 현행 보호막을 시차 운용으로 재설계 |
| 발동 | 정상 치유 주기, 유효 부상자 존재 | 보호막 재사용 가능, 유효 대상 존재 |
| 대상·범위 | 치유 거리 안 부상자 1명; HP 비율 동률일 때 보호 공백을 보조 기준으로 비교 | 현행 보호막 유효 거리 안 제한된 대상. 먼저 한 명, 짧은 시차 뒤 두 번째 대상을 재선정하는 안 |
| 효과 | 약한 반복 치유, 군의관의 큰 구조를 대체하지 않음 | 한 번의 총 보호 예산을 두 시점에 배분. 두 번째가 무료 추가 시전은 아님 |
| 주기·비용 | 정상 치유 간격 | 한 번의 재사용/시전 계약, 시차 사이 시전자 사망 시 미실행 부분 소멸 |
| 태그 | `normal_heal`, 지원 정상 치유 | `unit_skill`, `shield`, 보호막. 치유 태그 없음 |

- 특화는 보호막 AP 계수, 운용은 지속시간으로 남는다. 새 시차 운용이 지속시간을 무한 갱신하거나 특화 보호량을 두 번 지급하지 않도록 총량을 나눈다.
- 대상의 기존 보호막이 충분하면 다른 유효 대상을 우선한다. 재적용은 잔량 덧셈이 아니라 정해진 교체/최댓값 정책을 따르며 보호막이 보호막을 재귀 생성하지 않는다.
- 이미 두 행동이 있는 1차와의 차이는 '세 번째 스킬 추가'가 아니라 **피해 시점에 맞춰 보호를 나누는 2차 운용**이다. 시차가 의미 없이 불리하기만 하면 기본 동시형과 비교해 조정한다.
- 강점은 예고 공격 전 분산 보호, 약점은 보호 유효 창을 비껴가는 공격과 지속적인 체력 손실이다.

## 6. 3차: 4계열의 궁극 틀, 8분기의 다른 결과

### 공통 자격과 발동 상태

- 해당 2차 완성 + 해당 열쇠 보유 + 4장 각성 기회가 자격인 안이다. 열쇠는 I부터 인정하고 소비하지 않는 기존 제안을 따른다.
- 원정당 1명 각성부터 비교한다. 4개 열쇠를 모았다고 4명 무료 각성을 보장하지 않는다.
- 궁극은 **독립적인 세 번째 기술 슬롯**이다. 사용하면 다음 적격 기본 기술을 제한적으로 변환하는 '준비 → 유효 기본 기술에 적용 → 소모' 구조를 제안한다. 단순 상시 능력치 패시브를 궁극 버튼으로 가장하지 않는다.
- 두 기본 기술은 삭제·교체하지 않는다. 궁극 변환이 끝나면 원래 두 기술과 주기로 돌아간다. 궁극이 기본 기술의 재사용/마나를 자동 초기화하거나 공짜로 새 시전하지 않는다.
- 초기안은 전투당 1회로 비교하되 확정값은 아니다. 새로운 상시 관리 재화 없이 전투 내 준비 상태·남은 사용만 보여 준다. 여러 번 사용 안은 충전과 평균 출력을 다시 검증한 뒤 선택한다.
- 무효 대상에서는 준비 상태를 유지한다. 유효 행동에 결합해 발동 확정된 시점에 사용을 기록한다. 피해가 나중에 빗나갔다고 재접속으로 사용권을 돌려받지 않는다.

| **비전의 현자** / 비전의 씨앗 `arcane_seed` | 기존 주문의 공간 또는 발현 시간을 일회성 재설계 | 홍련형: 다음 폭염탄이 자신의 유효 잔불 지대와 연결되면 남은 잔불 피해를 짧게 압축해 터뜨림. 한파형: 다음 냉기 경계를 좁고 긴 진입 회랑으로 바꾸어 접근 방향을 다룸 | 홍련은 남은 지속 피해를 소모하고 잔불 없이 무료 폭발하지 않음. 한파는 피해 궁극/완전 빙결이 되지 않음 |

### 분기 변환의 구체적 안전장치

1. **수성형:** 연결 대상은 시작 상하좌우를 유지한다. 한 대상에 여러 보호 궁극을 곱하지 않는다. 한 번의 방벽을 여러 피격에 나눠 쓰더라도 총 완화량/유효 피격수/최대 지속 중 제한을 명시한다.
2. **돌파형:** 돌격 피해·표적 수를 두 번 지급하지 않는다. 빨라진 준비가 교전 시작 시점을 바꾸는 것이 핵심이고, 보스 밀치기·순간이동·무적 돌격은 아니다. 운용의 돌격 후 DEF와 돌격 칼집은 그대로 유효하다.
3. **일점형:** 기존 강화탄 AP 계수를 기반으로 계산해 특화 투자를 살린다. 추가 미래 예산을 썼다면 후속 사격 회복에 반영한다. 기본공격 버프를 한 번 적용하고 궁극 이름 때문에 다시 곱하지 않는다. 비치명 유지.
4. **탄막형:** 늘어난 대상 수에는 총 피해가 나뉜다. 대상이 적으면 잉여 탄은 사라진다. 일점형의 단일 위협 제거까지 동시에 최고가 되는 결과는 실패다.
5. **홍련형:** 압축 가능한 양은 그 시점의 실제 잔불 잔여 예산뿐이다. 이미 준 피해를 다시 주거나 모든 미래 장판 틱을 무제한 생성하지 않는다. 압축분은 원래 지속 피해 계통을 유지하고 새 유료 주문·치명·추가 낙인 발동으로 세지 않는다. 일반 폭염탄 비용/쿨다운은 그대로 지불한다.
6. **한파형:** 회랑은 시전 시 고정되고 맵 경계 안에 있다. 총 제어 예산을 늘리면 강도·지속·대상 중 다른 축의 비용을 둔다. 보스 둔화 절반과 지속 갱신 제한은 궁극에도 유지한다.
7. **구명형:** 분산 치유의 각 대상이 살아 있고 실제 결손 HP가 있어야 한다. 대상 부족/초과회복으로 남은 예산을 무한 재분배하지 않는다. 여러 치유 이벤트가 하나의 궁극 사용으로 연결되며 정상 치유 전용 발동을 추가로 열지 않는다.
8. **방호형:** 남은 보호 예산의 전달 시점만 바꾼다. 같은 보호막에 더하기→소멸→재전달을 반복하지 않는다. 특화의 보호량과 운용의 지속은 정해진 한 번의 산식에만 반영한다.

이 구조의 목적은 '궁극을 얻으면 모든 수치가 두 배'가 아니라 **지금 필요한 대상·공간·타이밍을 한 번 크게 바꾸는 것**이다. 순수 DPS·HPS가 비슷해도 위기 구간에서 지나치게 지배적일 수 있으므로 승률·피해 회피·과잉치유·완료 시간까지 비교한다.

홍련형처럼 두 기본 기술의 조합이 조건인 경우, 일반적인 마나/재사용 조건에서도 잔불이 끝나기 전에 다음 폭염탄을 합법적으로 시전할 수 있어야 한다. 잔불 지속·두 주문 간 행동 시간·필요 마나를 함께 검증하고, 궁극 준비 중에는 필요한 마나를 남기는 우선순위를 둔다. 기술 두 개는 각각 독립적으로 유효해야 하며, 궁극을 위한 조건이 두 기본 기술의 평상시 사용을 모두 막아서는 안 된다.

## 7. 자동과 수동: 제안은 구분하고 입력을 늘리지 않는다

### 권장 비교안 A: 두 기본 기술 자동 + 궁극 조건 자동

- 기본 기술은 기존 자동전투에 맞춘다. 기본 기술마다 9명 × 2개의 버튼을 만들지 않는다.
- 궁극은 전투 내 준비가 된 뒤 **유효한 큰 가치 상황**에만 적용한다. 예: 수성은 연결 아군에 큰 예고 피해, 돌파는 돌격 뒤 실제 피격 위험, 저격은 살아 있는 고위험 합법 대상, 연사는 분산 적 다수, 홍련은 의미 있는 잔불 잔여, 한파는 접근 무리, 지원은 실제 결손/예고 피해.
- 조건을 만족하지 않았으면 단지 시간이 흘렀다는 이유로 마지막 적에게 낭비하지 않는다. 사용하지 않고 전투가 끝나도 다음 전투에 사용권을 누적하지 않는다.
- 기준을 적에게 숨긴 완벽한 미래 예지로 계산하지 않는다. 플레이어가 볼 수 있는 예고/HP/거리와 같은 정보에 맞춘다.

### 비교안 B: 기본 기술 자동 + 각성 병사 궁극 1개만 수동

- 원정당 각성 1명 안에서는 플레이어 지휘 2개와 구분되는 **궁극 버튼 최대 1개**를 제안한다. 9명 × 3개 수동 입력은 만들지 않는다.
- 버튼은 바로 무료 공격을 생성하는 게 아니라 궁극을 준비시킨다. 현재 유효 대상/다음 결합 기술을 미리 보여 주고, 입력부터 실제 발동까지의 지연을 숨기지 않는다.
- 모바일에서 세 번째 주요 버튼이 과부하인지, 자동보다 수동 성능 차이가 필수 숙련 세금이 되는지 비교한다. 수동을 택해도 기본 기술은 계속 자동이다.
- 나중에 각성 인원을 늘린다면 이 입력안을 그대로 확장하지 않는다. 활성 궁극 1개 선택/공유 명령 등의 별도 설계를 먼저 검토한다.

**자동/수동·충전·전투당 횟수는 사용자가 확정한 사항이 아니다.** 위 두 안의 가독성·낭비율·조작량·성능 편차를 보고 선택한다. 궁극을 누르는 재미 때문에 지휘 기술이나 자동전투 자체를 밀어내지 않는다.

### 발동·대상·거리의 구현 전 비교 항목

| 축 | 우선 비교안 | 더 단순한 대안 / 주의 |
|---|---|---|
| 방벽·보호막 시점 | 보이는 공격 예고의 대상과 남은 시간을 활용 | 예고 정보 연결이 불완전하면 HP/근접 위험 기준부터 비교. 구현하지 않은 예지 능력을 현재 기능처럼 취급하지 않음 |
| 저격 고가치 표적 | 유효 거리 안 예고 공격 중인 적 우선, 다음은 남은 HP가 큰 적; 동률은 거리·고정 ID | 남은 HP 우선만 사용하는 단순안. 어느 쪽이든 매 틱 표적이 흔들리지 않도록 조준 중 잠금 |
| 지원 대상 | 낮은 HP 비율 → 실제 결손 HP → 거리 → 고정 ID | 보호막은 치유와 달리 예고 피해/기존 잔량을 우선할 수 있으므로 같은 선정 함수를 강제하지 않음 |
| 범위 강화 | 기본/훈련/유물 사거리에서 유한한 추가 범위만 허용 | 사거리 증가는 빼고 같은 범위 안 대상 우선순위만 바꾸는 안. 순간이동·전맵 조준으로 우회하지 않음 |
| 궁극 준비 | 전투당 유한 사용과 최소 준비 시간 뒤 조건 판정 | 병사 행동으로 충전하는 안은 빠른 공격 병과만 유리해지지 않는지 추가 검증. 초기안에 별도 게이지 관리까지 자동 포함하지 않음 |

이 값들은 병사마다 새 설정 메뉴에서 조정하게 하지 않는다. 우선 직업 정의와 읽기 전용 설명으로 제공하고 플레이어는 편성·훈련·유물·지휘의 기존 선택을 활용한다.

| 군의관 | 정상 치유 위급 배율 | 치유 기본 사거리 | 정상 치유가 사라져 응급 배율·유물의 대상이 없어짐 |
| 수호사 | 보호막 AP 계수 | 보호막 지속 | 고정량 궁극 보호막으로 기존 계수·지속을 무시 |

3차는 해당 2차의 병사·훈련·기술 ID를 유지하고 궁극 정의와 각성 자격을 덧붙이는 개념 모델이다. 이는 실제 스키마 변경 지시가 아니다. 구버전 원정에 새 기술을 소급하지 않으며, 새 원정 규칙과 구버전 저장 규칙을 구분한다.

### 8.2 유물 적용은 이름이 아니라 행동 태그로 판정

| 기존/제안 유물군 | 계속 적용할 대상 | 자동 확대하지 않을 대상 |
|---|---|---|
| 날 선 창끝, 궁 계열 평타 증가, 집중 사격 | 적격 평타와 명시된 강화 평타. 기존 강화탄 계약 유지 | 돌격 고유 피해·주문·보호·치유 |
| 예리한 눈 | 치명 허용 평타 | 저격 강화탄·신규 강화 일제 초기안·주문·궁극 압축 피해 |
| 비전 렌즈·과충전 핵·중열 공명석 | 계열/시작 열 조건에 맞는 AP와 그 AP를 쓰는 기술 | 궁극 별도 AP 보너스 재곱, 과충전의 마나 손해 제거 |
| 야전 구급낭·지원 시너지·진료 시계 | 지원 정상 치유 | 집중 수술·궁극 구조 배분·보호막·지휘 치유에 자동 적용 금지 |
| 집중 치료서 | 지원 AP, 현행 주기/초기 지연 대가 | 새 수술이 주기 대가를 완전히 회피하지 않도록 대응 비용 정의 필요 |
| 잔향 수정 | 적격 유료 주문 시전 1회씩, 실제 지불 비용 기준 환급 | 장판 매 틱·궁극 압축분·무료 파생 효과를 추가 주문으로 집계 금지 |
| 응급 붕대함 | 성공한 정상 치유의 기존 위급 조건·전투당 제한 | 0치유·집중 수술·궁극의 대상별 파생 치유에서 추가 발동 금지 |
| 연결 핀·전열 철판·복귀 휘장 | 시작 배치/직전 예비 회복 등 기존 자격 | 후퇴 기동·궁극·전투 중 사망으로 시작 조건 재계산 |
| 돌격 칼집·갈래 화살통·서리 고리 | 돌격 뒤 DEF, 적격 보조 탄, 명시된 서리 둔화 | 궁극이 같은 원인 이벤트를 중복 발생시켜 재발동 |
| 급행 모래시계·결전의 북 등 지휘 유물 | 해당 지휘 기술 | 병사 기본 기술/궁극의 재사용·마나·지속에 무단 적용 |

새 치유/주문이 기존 유물 대상에서 제외되는 것은 설명으로 보여 준다. 다만 제외가 많아 3장에 모은 유물이 4장에 쓸모없어지면 '설명이 맞으니 괜찮다'고 하지 않고 기술 빈도·예산을 조정한다. 필요하면 기존 유물의 적용 범위를 명시적으로 확장하는 안을 별도로 승인·검증한다.

### 8.3 실제 코드 상한을 우회하지 않는다

현행 수치를 1.0 초기 안전 기준으로 사용한다. 신규 최종 밸런스 수치가 아니다.

- HP/ATK/AP 양의 증가 합계 각각 +50%, DEF 비율 증가 +50%, 유물의 평면 DEF 합계 +40, 방벽 연결 DEF +20.
- 평타·지원 정상 치유·보호막·마법 고유 피해 보너스는 해당 항목 각각 +35%.
- 최종 피해 감소 55%, 공격속도 증가 50%, 이동속도 증가 25%, 마나 재생 증가 50%.
- 병사 기술 재사용 감소 15%, 지휘 기술 재사용 감소 20%. 서로 다른 상한이며 궁극이 제3의 무제한 감소 경로를 만들지 않는다.
- 치명 확률 50%, 치명 배율 최대 2.5배, 잔향 환급 50%. 비치명 행동을 궁극이라는 이유로 치명 허용하지 않는다.
- 처치·치유·보호막·유료 주문에 원인 행동 ID를 둔다. 파생 효과가 자기 자신을 다시 발동시키지 않는다.

**상한 준수만으로 밸런스가 맞는 것은 아니다.** 동시 행동 수·대상수·피해 틱 수·보호막 가동률·제어 유지율·초과 피해/치유·공격을 못 한 시간까지 기록한다. '계수 상한은 같지만 타격이 세 번'인 궁극은 여전히 별도 전투 예산을 쓴다.

## 9. 적·사건·유물과 연결하되 정답 병과를 강제하지 않는다

아래는 선택을 드러내는 상황 예시이며 신규 적/사건 전체를 추가 제작하라는 범위가 아니다.

| 상황 | 돋보이는 기술 | 같은 상황의 다른 합법 대응 |
|---|---|---|
| 소수 전열에 예고 강타 | 방벽 전개, 교대 방벽 | 지휘 수호, 공격 전 표적 제거, 전열 배치 조정 |
| 앞선 적 뒤에 위협적인 원거리 적 | 고정 조준, 제한된 돌격 | 가까운 적부터 줄이기, 생존 유물·회복으로 압박 견디기 |
| 여러 방향의 작은 적 | 일제 사격, 폭염탄/잔불 | 저격 순차 제거, 전열 유지와 지휘 집중 |
| 빠른 적의 전열 접근 | 냉기 경계, 후퇴 기동 | 더 두꺼운 전열, 집중 화력, 보호 타이밍 |
| 살아 있는 아군의 큰 체력 손실 | 집중 수술 | 정상 진료·지휘 응급 회복, 미리 보호, 전투 뒤 휴식·교대 |
| 긴 연속 전투 | 마나 효율·치료 사거리·보호 지속 훈련 | 제련/지휘 연구/예비 교대·야영의 다른 자원 선택 |

- 2장 '잊힌 병법서'·훈련 기회는 두 기술 중 하나를 열쇠로 잠그는 곳이 아니라 운용 방식을 확인하는 장소다.
- 3장 '유물 추적자의 제안'은 지정 목표의 도달 가능한 기회를 준다. 일반 풀은 출전 기준, 지정 목표만 예비 포함 보유 전체 기준을 유지한다.
- 열쇠를 얻지 않는 플레이도 해당 장에서 기본 기술용 유물을 얻는다. 상점 자금·정예 위험·다른 보상 포기라는 비용을 비교할 수 있어야 한다.
- 4장은 궁극 시험을 할 수 있는 상황을 주되 각성 소유 여부에 따라 적을 몰래 강화하거나 '궁극으로만 깨는 방패'를 두지 않는다.
- 5장은 이미 본 압박을 조합한다. 특정 병과·특정 열쇠·전설 유물의 보유 검사를 통과 조건으로 두지 않는다.

## 10. 검증 기준과 다음 결정

### 기술 계약 검증

1. 8개 2차 모두 평타를 제외한 고유 기술이 정확히 2개다. 강화 평타는 일반 평타와 별도 고유 상태/주기를 실제로 갖는다.
2. 3차는 같은 두 기술을 유지하고 궁극 1개만 추가한다. 궁극이 끝난 뒤 기본 기술 상태·재사용·마나가 정상적으로 이어진다.
3. 8역할 × 2훈련 경로의 16진입 조합에서 능력치·대상/사거리·기술 태그·자격이 이어진다. 시너지 인원은 여전히 병사 1명이다.
4. 평타 대체/미래 공격 예산 당김/시전 중 공격 정지/공용 마나가 실제 시간축에서 일치한다. 표시상 대가만 있고 전투에서는 무료 추가 행동이 되는 경우는 실패다.
5. 대상 없음·대상 사망·범위 이탈·시전자 사망·궁극 준비 중 전투 종료·불러오기에서 중복 발동/환불이 없다.
6. 다중 표적 부족 시 남는 탄 소멸, 장판 중첩 제한, 보스 둔화 절반, 보호막 비재귀, 0치유 미발동, 강화탄 비치명을 검증한다.

### 역할과 재미 검증

- 같은 비용/훈련/유물 수준에서 2차 기본 기술 2개가 각 역할을 설명하는가? 두 번째 기술이 대부분 전투에서 한 번도 의미 있게 작동하지 않는다면 이름만 채운 것으로 본다.
- 방벽↔돌격, 저격↔연사, 폭염↔서리, 군의관↔수호사의 우세 상황과 약점이 3차에서도 서로 다르다.
- 2차 대비 3차의 평균/최악/최고 효율을 나누어 본다. DPS뿐 아니라 생존 시간·회복/보호 실효량·처치 대상·큰 피해 회피·궁극 낭비를 측정한다.
- 짧은 일반전의 개막 순간 화력과 긴 보스전의 평균 출력을 따로 본다. 미래 공격을 당기는 기술은 전투가 끝나면 후속 공백을 실제로 지불하지 않을 수 있으므로 평균 DPS 하나만으로 공정하다고 판정하지 않는다.
- 3장에서 얻은 유물의 실제 기여가 4·5장에도 남는다. 궁극이 나머지 8명과 기존 훈련을 배경으로 만들면 궁극의 빈도/범위/예산을 줄인다.
- 궁극 0, 열쇠 0, 비전설 조합에도 일반 5장 완주 경로가 있다. 특정 병과 1종을 빼면 반드시 실패하는 보스는 재설계한다.
- 자동 궁극과 수동 궁극의 유효 발동률·실수·조작 수·모바일 가독성을 비교한다. 버튼 수가 아니라 실제 의사결정 부담을 본다.
- `five-chapter-run.md`의 4장 진입 각성 이후14전투(5장7전투 포함)는 **남아 있는 전투 기회**다. 그 병사의 실제 출전이나 궁극 사용이 보장된다는 뜻이 아니다. 병사별 출전 전투 수, 기본 기술 1·2/궁극의 첫 발동 시간·유효 발동 수·무발동 사유(예비/사망/대상 없음/자원 부족/조건 불충족/사용 보류)를 따로 기록한다.

### 이 문서에서 이어서 결정할 소수 항목

1. 2차 8종의 가칭과 훈련 II 자격 통합 여부. 기존 1차 단계는 유지한다.
2. 후퇴 기동의 실제 이동 vs 짧은 방어 대안, 수호사의 시차 보호처럼 구현 범위가 큰 두 번째 기술부터 비교한다.
3. 궁극 자동 조건형 vs 궁극 하나만 수동형. 원정당 각성 수와 전투당 횟수도 같은 입력/전투 예산 안에서 결정한다.
4. 기술별 대상·범위·주기·비용·전후 행동 시간을 채우고 같은 편성의 타임라인을 비교한다. 이 문서 단계에서 임의 최종 계수를 확정하지 않는다.
