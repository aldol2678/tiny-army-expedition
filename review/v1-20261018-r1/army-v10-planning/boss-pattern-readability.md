# 1.0 보스 패턴과 읽을 수 있는 대응

2026-10-18 UTC. 로컬 설계안. 제품 코드·저장·빌드·배포 변경 없음. 아래 신규 패턴, 시간, 단계 전환, 검증 기준은 **미구현·미검증 제안**이다. 전투 승률을 측정한 결과가 아니다.

## 결론

보스 수보다 전투 질문을 늘린다. **5장 보스 5종, 각 2~3개 패턴**이면 충분하다. 강타를 피하라는 액션 게임이 아니라, 자동전투를 읽고 **보호를 언제 쓰고, 피해 뒤 언제 회복하고, 누구를 먼저 줄일지** 고르는 게임으로 만든다. 장당 모든 경로 최소 7전투(보스 포함), 총 최소 35전투는 유지한다. 분기 노드·재등장·패턴 순서 변형을 별개 보스로 세지 않는다. 75종 신규 보스를 제안하지 않는다.

## 1. 확인된 현재와 새 설계의 경계

근거는 실제 dist/js/game-engine.js, content.js, v09-content.js, game-ui.js, battle-readability.js와 planning의 README.md, encounter-event-sets.md, skill-implementation-contracts.md다.

- 현행 콘텐츠는 2장: 평원의 파수꾼 / 철성의 문지기. 둘 모두 같은 boss 타입의 강타를 쓴다. 차이는 호위 구성이다.
- 실제 v09 tick의 보스 강타: 최근접 자동 표적 거리 <150일 때 그 시점 위치에 반경 150 원, 준비 2.1초, 공격력×2 물리 피해, 발동 시작 때 다음 skillCd=9초. 강타병은 반경85/1.5초/×1.6/12초다. 시전자 사망 시 미해결 원이 취소된다.
- 현재 원이 떠도 보스의 이동·평타는 계속된다. **준비-공격-회복 행동 잠금은 현재 기능이 아니다.** 따라서 새 후딜 모션만 그려 놓고 실제 평타를 허용하면 거짓 안전 신호가 된다.
- 원은 시전 때 고정된다. 원 밖 이동은 자동전투의 부수 효과이지 사용자 회피 기술이 아니다. 전투 중 자유 이동·진형 변경·교대·공통 차단기 없음.
- 지휘 2칸, PC 1/2는 해당 칸의 실제 장착 기술을 실행한다. 집중 사격은 표적 선택 동안 일시정지하며 정상 사거리 안 우선순위다. 전맵 저격·도발·강제 접근·차단이 아니다.
- 기본 지휘 재사용은 회복24초 / 수호20초 / 집중18초 / 사기26초다. 수호4초, 집중6초, 사기5초. 회복은 생존자 최대HP15%, 수호는 방어 적용 뒤20% 감소(공통 최종 감소 상한55%), 사기는 평타 가속이다. 유물 투영값이 우선한다.
- 따라서 9초마다 오는 강타를 매번 지휘 수호로만 넘기라는 설계는 성립하지 않는다. 아래의 지휘는 위기 완화 선택이며 매 주기 필수 열쇠가 아니다.

## 2. 모든 보스의 공통 실행 계약

### 패턴 상태와 수치의 의미

시간은 시뮬레이션 초 기준 초기 시험값 P0다. 각 표의 `예고 → 시전 → 타격 → 회복`은 서로 겹치지 않는 순차 상태다. 예고+시전이 실제 대응 시간이며 총합을 UI에 표시한다.

- 예고 시작: 대상 ID/지면 중심/방향 고정, 모양·패턴 이름·전체 남은 시간 노출. 이후 몰래 추적 금지.
- 시전: 팔/활이 끝 자세로 향함. 새 잠금 시점이 아니라 이미 고정된 범위를 강조한다. 전용 피해 없음.
- 타격: 원/부채의 예고 형상 그대로 판정. 잔광은 판정과 구별하고 별도 피해 없음.
- 회복: 패턴 소유자는 이동·평타·새 능력 모두 중단, 계속 피격 가능. 무적/피해증폭 보너스는 붙이지 않는다. 끝나고 평타 재개. 쌓인 평타/능력을 한 틱에 몰아 쓰지 않는다.
- 패턴 중 사망은 미해결 공격 취소. 호위 사망은 해당 호위 발사만 취소. 전투 종료 후 연출을 위해 사망/승리 판정을 지연하지 않는다.
- 대기 구간에는 평타를 할 수 있으나 반드시 '회복 공백'과 다른 자세다. 개막 최소4초는 접촉/대형 읽기 시간이며 공격 범위에 대상이 없는 패턴은 대기한다.
- 각 보스는 한 번에 패턴 하나. 호위 V/K도 같은 조우 스케줄러에 참여하여 무작위 중첩을 막는다. P0는 동시에 위험 형상 최대1개, 4~5장의 선행 예고 추가는 최대2개까지 별도 검증 후 검토한다.

### 피해 예산

새 패턴을 기존9초 강타 위에 덧붙이지 않는다. 같은 시간 창의 적 총 피해 기대량, 최대 집중 피해, 피해 대상수, 호위 평타 정지를 함께 계산해 기존 예산을 **재분배**한다. 2연타는 두 번 모두 기존 강타 피해를 주는 것이 아니다. 원이 커지면 대상수 증가까지 반영한다. HP단계 전환은 공격력·공속·호위 수를 동시에 올리지 않는다.

정확한 계수는 보류한다. 승인 기준은 '주력 전열과 후열의 대표 합법 성장 상태에서 완전한 단일 주기를 지휘 없이도 버틸 수 있는 조합이 있고, 2개 지휘를 써도 피할 수 없는 급사는 없다'다. 무조건 모든 빌드가 이겨야 한다는 뜻은 아니지만 특정 직업/유물/궁극 보유가 정답표가 되어서는 안 된다.

## 3. 다섯 보스의 질문·패턴

장 이름·보스 이름은 기존 조우 제안과 맞춘다. 3~5장 이름은 가칭. 초 단위 숫자는 최초 비교 프로필일 뿐 최종 난도가 아니다. 모든 패턴은 새 행동 스케줄러 구현이 필요하다.

### 1장 평원의 파수꾼: 큰 한 번 뒤에 공격할 시간을 확보할까?

1. **방패 내리찍기**: 큰 원+방패 아이콘. 예고1.8 → 시전0.4 → 단발 → 회복2.5초. 최근접 합법 대상 위치 고정 원. 기존 강타를 읽기 좋게 재설계한다.
2. **전열 찍기**: 작은 원+망치 아이콘. 예고1.2 → 시전0.4 → 낮은 단발 → 회복1.8초. 큰 원과 피해 예산을 나눠 사용하는 약한 패턴이다.

첫 주기는 큰 원 하나로 가르친다. 이후 큰 원→평타 대기→작은 원→대기로 고정하며 최소 주기 길이16초 후보. HP단계 없음. 큰 원 뒤 짧은 진동과 무릎을 굽힌 회복 자세를 보여준다.

- 전투 중: 큰 타격 직전 수호, 피해 후 생존자 회복, 회복 자세에서 사기/정상 사거리 내 집중 중 실제 장착한 행동 선택. 두 슬롯으로 모두 해야 한다는 요구 없음.
- 준비 A: 튼튼한 전열+기본 원거리/마법+지원, 수호/회복. 느리지만 피해 후 복구.
- 준비 B: 전열 두 접점+다중 또는 여러 단일 딜러, 집중/사기. 접근한 호위를 먼저 줄이고 보스 공백 공격. 지원/특정 진화 없음도 검증한다.
- 분산은 시작 접촉을 바꾸는 보조 선택일 뿐, 원이 자동으로 빗나간다고 안내하지 않는다.

### 2장 철성의 문지기: 강타와 사격 중 어느 압박을 먼저 줄일까?

1. **성문 강타**: 큰 원+문짝 아이콘. 예고1.8 → 시전0.5 → 단발 → 회복2.3초.
2. **호위 일제**: 살아 있는 V호위의 각 전방 부채, 활+3눈금. 예고1.5 → 시전0.5 → 0.6초 동안3회 분할 → 재장전3초. 각 호위의 총3발 피해를 기존 단발 예산에서 분할하며 3배로 만들지 않는다. 방향은 예고 시작 때 고정된다.

강타 회복 종료 뒤 일제를 시작한다. 일제 동안 보스는 명령 자세로 공격 정지, 일제 회복 때 양쪽 모두 공백. 주기 최소18초 후보. 체력60% 아래에서는 다음 완전 주기부터 순서만 일제→강타로 변경, 3초 전 '사격 먼저'를 표시한다. 피해/주기는 그대로다.

- 전투 중: 수호를 두 공격 중 위험한 쪽에 남기거나, 첫 타격 후 회복해 다음 공격을 준비. 집중은 접근 가능한 V를 줄일 때만 효과적이며 사거리 밖 V 집중이 전열을 통과하게 하지 않는다.
- 준비 A: 전열 유지+원거리 또는 마법 단일 누적 피해, 집중/회복. V 접근까지 앞 적부터 정상 제거한다.
- 준비 B: 높은 전체 내구+회복/보호 기능, 수호/사기. 일제를 버티고 공동 재장전 공백에서 공격한다. 방벽병/수호사 전용 검사는 없다.
- 호위를 못 죽여도 생존 해법이 있어야 한다. 죽인 V의 패턴은 빈 명령 자세 후 짧은 공백으로 끝나고 재소환하지 않는다.

### 3장 봉인의 기록관: 작은 피해를 받아내고 큰 피해에 자원을 남길까?

1. **좁은 각인**: 작은 원·한 줄 무늬. 예고1.2 → 시전0.4 → 낮은 단발 → 회복1.8초.
2. **넓은 각인**: 큰 원·두 겹 무늬. 예고2.3 → 시전0.5 → 큰 단발 → 회복3초.

좁은→평타 대기→넓은→회복이 한 주기, 최소18초 후보. 좁은 타격 후 큰 예고 시작 전 최소2초 보장. 신규 K호위도 독립 강타를 끼워 넣지 않고 보스 대기 구간에서만 허가한다. 원2개 동시 타격은 하지 않는다. HP50% 이후도 같은 순서를 유지하고 연출·문구만 전환한다.

- 전투 중: 작은 피해를 자동 치유 또는 회복으로 복구, 넓은 예고 때 수호. 공격형2칸이면 호위 제거 후 큰 각인 뒤 공백에 집중/사기를 나눠 쓴다. 각인에 임의 차단 취약점 없음.
- 준비 A: 반복 회복 기능+내구 전열+지속 딜러, 수호/회복. 큰 피해를 줄이고 반복 회복한다.
- 준비 B: 전열 분산 접점+접근 호위를 빨리 줄이는 공격 기능, 집중/사기 또는 집중/수호. 넓은 패턴을 최소 한 번은 받을 수 있는 HP투자를 포함한다.
- 특정 유물/열쇠/마법 피해를 요구하지 않는다. 유물은 이미 가능한 행동의 효율을 높일 뿐 문을 여는 암호가 아니다.

### 4장 깨어난 성주: 큰 자원을 쓴 다음에도 다음 위협을 처리할까?

1. **성주 강타**: 큰 원+관. 예고2.0 → 시전0.5 → 단발 → 회복2.5초.
2. **호위 일제**: 2장과 동일 문법. 예고1.5 → 시전0.5 → 0.6초3분할 → 공동 회복3초.
3. **지친 반격**: 작은 원+깨진 무기. 예고1.4 → 시전0.4 → 낮은 단발 → 회복3초.

강타→일제→지친 반격, 최소24초 후보. 세 공격을 기존 두 패턴 예산 안으로 나누며 각 패턴 사이 최소2초 무공격 간격을 보장한다. HP50% 이하의 다음 주기부터 지친 반격→강타→일제로 순서만 바꾸고 다음2개 아이콘에 미리 표시한다. 새 패턴 잠금 해제나 피해2배 없음.

- 전투 중: 첫 큰 패턴에 수호, 후속에 회복 또는 다음 공백에 공격 지휘. 지휘가 모두 쿨이면 내구/자동 회복으로 버틸 주기여야 한다. 궁극은 자동/수동 정책 미정이므로 특정 시각 직접 발동 요구 없음.
- 준비 A: 기본2기술의 피해/유지 역할을 혼합, 궁극 없이 수호/회복으로 순환.
- 준비 B: 빠른 호위 제거+기본 단일 공격, 집중/사기. 궁극이 있다면 여유를 늘리되 첫 구간에 모두 소모해도 뒤가 막히지 않는다.
- 무적 대기나 불필요한 체력 증량으로 궁극 충전을 강제하지 않는다.

### 5장 최후의 파수군주: 이미 배운 신호를 보고 목표와 지휘 시점을 바꿀까?

1. **왕좌 강타**: 큰 원. 예고2.0 → 시전0.5 → 단발 → 회복2.5초.
2. **호위 일제**: 부채+3눈금. 예고1.5 → 시전0.5 → 0.6초3분할 → 회복3초.
3. **봉인 각인**: 작은 원. 예고1.4 → 시전0.4 → 낮은 단발 → 회복2.5초.

잔병은 개막 편성만 존재하며 재소환 없음. 기본 강타→일제→각인, 최소24초 후보. HP60% 다음 완전 주기부터 각인→강타→일제, HP30% 다음 주기부터 일제→각인→강타. 전환3초 전에 다음2개 아이콘과 짧은 문구. 진행 중 공격을 끊고 중복 시작하지 않는다. HP가 한 번에 여러 문턱을 넘으면 마지막 해당 단계만 예약한다.

- 전투 중: 살아 있는 호위가 위협이면 사거리 내 집중, 보스만 남으면 보스 공백 집중/사기. 수호는 큰 원 또는 살아남은 V의 일제에 배분, 회복은 피해 뒤 사용.
- 준비 A: 여러 단일 또는 다중 공격 기능+충분한 전열 내구로 호위를 줄여 후반을 단순화. 집중/사기 또는 집중/회복.
- 준비 B: 반복 회복/보호 기능+균형 지속 피해로 세 패턴을 견딤. 수호/회복. 특정 지원 진화가 아닌 여러 기본 지원/전열 구성도 비교한다.
- 궁극0·희귀유물0·영구연구0 경로를 반드시 별도 시험한다. 후반 단계마다 공격력/공속 배수를 올리거나 호위를 되살리지 않는다. 호위를 죽인 성과가 끝까지 남는다.

## 4. 가시성·모바일 계약

- 보스 HP바 아래 '현재 패턴명 · 남은 시뮬레이션초'와 다음2개 아이콘만 표시한다. 경고 문장은 '회피하세요' 대신 '큰 타격 준비', '3회 사격', '회복 공백'처럼 사실을 말한다.
- 고정 원은 외곽선+바닥 저채도 면+방향 없는 무늬, 부채는 꼭짓점/양끝선+3발 눈금. 색상 외 형태와 문구로도 구별한다. 단계 변화는 숫자와 패턴 순서로 알린다.
- 장판이 병사를 가리지 않도록 면 채도/불투명도는 낮게, 외곽과 카운트는 높게. 궁극/지휘/치명 이펙트보다 적 예고·HP바·버튼의 정보 우선순위가 높다.
- 준비 중 보스 상체/무기 들기, 시전 순간 고정 자세, 타격 접촉, 실제 무공격 회복자세를 연결한다. 취소되면 원/카운트/시전 자세를 함께 제거한다.
- 모바일에서는 모든 적 이름·피해 숫자를 동시에 늘리지 않는다. 현재 보스 패턴1개, 다음2개, 지휘2개에 우선 공간을 준다. 작은 화면에서도 지휘 버튼 최소44 CSS px 후보, 현재 기술 이름과 재사용 숫자 유지. PC1/2 표기를 모바일 필수 정보로 강요하지 않는다.
- 집중 표적 선택의 기존 일시정지와 취소를 유지해 작은 화면 탭 정밀도를 완화한다. 선택 중 게임 시간/예고 시간이 함께 멈춰야 한다.
- 카메라 확대/흔들림은 예고 경계나 입력 좌표를 어긋나게 하지 않는다. 현재 battle-readability의 투영/역투영 경로를 공통 사용한다. 모션감소에서도 원, 카운트, 타격 순간, 회복 상태는 남긴다.
- 순수 시각 효과 간소화 옵션으로 패턴 정보가 없어져서는 안 된다. 음소거/색 구별 어려움/입자0 각각 별도 확인한다.
- 2배속이 있다면 예고2초는 현실1초다. 배속별 실제 반응시간을 검사하며 짧으면 보스 패턴 중 자동 감속을 제안하기 전에 사용자 설정과 충돌 여부를 결정한다. 임의 감속은 본 설계의 확정 기능이 아니다.

## 5. 제작 순서와 출시 전 반증 시험

1. 현재 파수꾼 한 마리로 행동 잠금/고정 예고/실제 회복 공백을 구현·검증한다. 같은 리플레이에서 판정과 렌더의 차이를 먼저 없앤다.
2. 작은 원/큰 원/호위 부채의 3가지 공통 행동을 구현한 뒤 5개 프로필의 순서와 미술 실루엣을 바꾼다. 4~5장만 전용 신기술을 계속 추가하지 않는다.
3. 기존35전투 지도에서 일반/정예는 해당 보스 신호를 미리 보여준다. 새 필수 전투나 무보상 학습 대기를 추가하지 않는다. 선택 분기로 학습 조우를 못 봐도 첫 보스 예고가 자족적이어야 한다.
4. 각 보스의 준비 A/B를 같은 장 성장예산·컨디션·출전수로 비교한다. 최소 각 두 기능조합, 특정 대표직업 제거, 희귀유물 제거, 궁극 제거, 지휘 미사용/적절시점/너무이름을 포함한다. 승률/전투시간/사망시점은 실제 측정 후 기록하며 지금 PASS라 부르지 않는다.
5. 지휘별 실제 쿨다운으로 60초 이상 연속 주기를 검사한다. 첫 주기만 수호로 살고 둘째 불가피 전멸이면 실패다. heal+guard만 유일해법, focus+rally만 유일해법 모두 실패다.
6. 로그에는 bossActionId, phase, lockedTargets/shape, announceTick, resolveTick, recoveryUntilTick, phaseSwitchQueued, cancelReason, 실제 피해/흡수/치유를 남긴다. 렌더 프레임률은 판정을 바꾸지 않는다.
7. 자동 공격과 강타가 같은 틱 중복되는지, 호위 제거 후 빈 순서가 즉시 연쇄되며 주기가 빨라지는지, HP문턱 다중 통과가 중복 시전하는지, 집중으로 사거리 밖 공격이 발생하는지 검사한다. 발견 시 출시 보류.
8. 360px/390px 모바일과 PC에서 무음·모션감소·밀집 전열·최대 출전·동시 지휘/궁극을 캡처한다. 관찰자가 현재 위협/대상/남은 시간/다음 안전공백을 식별하지 못하면 장식 추가보다 경고 축소·정렬을 먼저 한다.

핵심 중단 조건: 겉모양만 바뀌고 다섯 보스의 실제 선택이 모두 '수호 누르기'로 같다면 다양화 실패다. 반대로 사용자에게 존재하지 않는 회피/차단을 요구해도 실패다.
