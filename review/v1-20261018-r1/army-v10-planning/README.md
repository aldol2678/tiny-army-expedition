# 꼬마 군단 원정대 1.0 · 시드 분기 지도 개정
2026-10-18. 설계 문서와 독립 검증 모델만 수정. 제품 코드·운영 저장·게임 배포는 변경하지 않았다.

## 현재 기준
- 5장, 각 장 모든 적법한 경로 최소7전투. 보스를7에 포함한다는 명시적 해석으로 최소35전투다.
- 무작위 seed로 간단한 노드 분기 지도를 생성한다. 별도 합류/빈 휴식/강제보스전 대기 화면을 없앤다. 실제 회복 선택이 있는 휴식만 선택 서비스로 유지한다.
- 서비스는 필수 전투층 사이의 덧붙임이며 전투를 대체하지 않는다. 기본안은6전투층+보스, 폭2~3, 선택서비스0~2/장, 보스 사전 공개다. 폭·서비스 수는 구현 제안이다.
- 3장 유물수집, 4장 궁극진입, 5장 활용. 2차 고유기술2개, 3차 기존2+궁극1.
- 구2장 진행 저장은 기존 규칙 그대로 끝낸다. 새로운1.0 원정만 새 규칙을 사용한다.

## 읽을 순서
1. [지도 청사진](chapter-node-blueprint.md): 생성·분기·XP 보상 이관·저장 계약.
2. [5장 원정](five-chapter-run.md): 성장 지점·35전투 시간 민감도·피로 위험.
3. [경제 재감사](economy-audit.md): 34보상 후보안과 기존 금액 유지 시450/550G 민감도. 가격/회복은 미확정.
4. [검증 모델](economy-model/README.md): 1,000 seeds×5장 지도 및 저장 fixture 검사와 원시 결과.
5. [유물 대도감](relic-catalog.md): 72종 보존, 첫 검증25종·조건부11종·후속36종, 공통 실효/대가 미리보기와 고정 획득 계약. [검토 대응](relic-review-response.md).
6. [출시 검증 계획](release-balance-plan.md), [통합 감사](design-audit.md).

기존 기술·유물·사건·저장 상세 문서에서는 상단 개정 공지가 우선한다. 20개 조우 후보는20전투 원정이 아니라 재사용/변형할 콘텐츠 풀이다. 35개 고유 조우 완성을 주장하지 않는다.

## 폐기 및 미확정
구20전투·19보상·고정서비스·합류유지·필수휴식·36~49분 모델은 [보관본](archive-20-battle/README.md)으로 이동했다. 그 구매/컨디션 결과는 새 지도에 적용하지 않는다.

34보상, 성장 선택 시점, XP3/1/1/1/1/2/1, 가격, 각성0G/1명, 회복량, 전투시간은 비교 제안이다. 지도 검증 PASS는 전투승률·궁극발동·제품저장·실제플레이시간 통과가 아니다. 이 문서만으로 출시하지 않는다.
