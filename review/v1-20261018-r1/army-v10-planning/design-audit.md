# 35전투 시드 지도 통합 감사
2026-10-18.

- 최신 우선순위: README → chapter-node-blueprint → five-chapter-run/economy-audit → economy-model. 기존 상세 문서 상단의 대체 공지를 먼저 적용한다.
- 20전투/19보상/20서비스/합류유지/필수보스휴식/36~49분의 이전 결론을 현행 문서와 모델에서 분리 보관했다.
- 최소7은 모든 적법한 경로에 적용하며 보스 포함이라는 해석을 공개했다. 서비스 방문은 추가 행동이지 전투 대체가 아니다.
- 3장수집·4장궁극진입·5장활용, 2차2기술·3차2+궁극, 구2장 저장 불변 유지.
- 합류·서비스 완료XP 제거분은 전투 이정표로 이관 제안했다. 총XP50과 출전 임계 시점을 명시했다. 제품 구현은 아직 없다.
- 34보상과 기존골드450/550G는 인플레이션 검토용 안/민감도다. 과거 최종병력·유물·각성 수를 재사용하지 않는다.
- 랜덤 지도 검증은 seed 재현성·DAG 전 경로 최단/최장 전투수·도달성·서비스 상한·XP·저장 fixture를 검사한다. 전투 밸런스/시간/제품 저장은 미검증.
- 조우 후보20종은 전투20회를 의미하지 않는다. 35전투에 후보 반복·변형 배치는 추가 설계가 필요하며 35개 고유 조우를 만들었다고 주장하지 않는다.
