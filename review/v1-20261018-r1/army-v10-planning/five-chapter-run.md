# 1.0 5장 원정 · 35전투 최소 개정
2026-10-18. 현행 설계 기준은 chapter-node-blueprint.md다. 예전 20전투·19보상·고정 서비스·36~49분은 폐기 비교안이며 archive-20-battle에만 보관한다.

## 원정 흐름
- 1장 7전투: 역할·진화·훈련 I를 익힌다.
- 2장 7전투: 열쇠 없이 주력 2차 고유 기술 2개를 완성하고 사용한다.
- 3장 7전투: 유물을 수집하고 목표 열쇠 선택 기회를 얻는다.
- 4장 7전투: 진입 시 조건부 궁극 각성 선택, 기존 기술2+궁극1을 실전에 사용한다.
- 5장 7전투: 빌드 활용, 최종 보스 뒤 정산.

장당 최소7에는 보스를 포함한다는 명시적 설계 해석을 둔다. 최소35는 모든 적법한 서비스·일반·정예 경로에 적용한다. 노드 수가35라는 뜻이 아니며 선택 서비스는 추가된다. 기본안은 전투를 정확히35회로 생성하되 이후 버전에서 더 늘려도 하한은 유지한다.

## 성장 및 선택 기회 (수치는 미확정)
주력의 진화를 전체 전투2, 훈련 I를5, 훈련 II/2차를8 뒤에 제시하는 안이다. 마지막 선택 시2차 두 기술을 갖고 이후27전투의 기회가 남는다. 동일 대상에 올바른 순서로 투자할 때만 가능하다. 열쇠와2차가 있다면 3장보스(전체21) 보상 뒤 4장 진입에 선택적 각성, 이후14전투, 그중5장7전투가 활용 기회다. 실제 발동 횟수가 아니다.

전투1~34 뒤 선택 보상창1개, 마지막35는 정산만 하는 **34보상 후보안**을 별도 시험한다. 구19개보다15개 증가하므로 군단 전체2차·유물 수·성장 상한을 이전 모델에서 복사하지 않는다. 매 보상에서 모집/성장/유물을 모두 주는 것이 아니다. 보유20명·출전9명·격자12칸을 구분하고, 보유19에서 모집2명이면1명만 수용, 초과를 재화/성장으로 바꾸지 않는다. 고유 유물 중복·무효 제련·부적격 성장의 무료 재추첨 악용을 금지한다.

## 간략 지도와 시간
장 시작에 보스·간단 지도·현재 갈림길을 함께 보여준다. 보스 전 휴식/합류/장 입장용 별도 대기 화면은 없다. 의미 있는 휴식·상점·사건만 선택 분기이며 최대2개/장, 무료 직행 가능하다. 전투 보상은 결과 패널에 합친다.

시간은 아직 실측하지 않았다. 전투당45~75초 가정이면35전투가26.25~43.75분이다. 편성·보상·노드 선택·로딩 합산15~25분을 가정하면 총41.25~68.75분이다. 모두 민감도 예시이지 확정 목표/플레이 결과가 아니다. 지도 축약으로 전투15회 증가분까지 상쇄했다고 주장하지 않는다. 첫 플레이·실패·재도전·모바일 조작은 별도 계측하며 장별 중단/재개를 정상 경로로 둔다.

## 피로와 기존 투자
필수+35휴식을 없앤 뒤 구90컨디션 장말 결과를 적용하지 않는다. 일반6×4+보스10=34/장 소모, 회복/부상 없이5장을 돌면170 소모다. 정예 증가·전투불능은 더 불리하므로 회복량/전투 소모/예비 회복/휴식 기회 재조정은 실제 전투 검증 전 미확정이다. 휴식이나 특정 병과를 필수 통행세로 만들어 해결하지 않는다. 기존 병사 ID·훈련·유물·배치 투자 보존을 검증한다.

## 저장 전환
0.9의 진행 중2장 원정은 그대로 구 규칙으로 끝낸다. 새 게임에만 1.0 지도/XP 원장/35전투 최소를 적용한다. 기존 저장의 장 수·지도·XP를 인플레이스 변환하거나 구2장 종료를5장 종료로 인정하지 않는다. 상세 새 계약은 chapter-node-blueprint와 save-version-transition의 개정 우선순위를 따른다.

## 유물 획득·검증의 연결 계약

유물 후보72종은 보존하되 첫 검증25종(기존17+열쇠18~21+배치26~29), 조건부 다음11종, 후속36종으로 구분한다. 34보상 기회는 유물34개가 아니다. 카테고리→희귀도→적격ID→사전 고정 fallback 순서와 동일 선택 예산을 지키며, 편성 조작/중복/포화로 카테고리를 다시 추첨하지 않는다. 실효 증가·대가·의미 있는 조건·남은 이용처·각성 자격은 [대도감 §3·§8](relic-catalog.md)의 공통 preview/획득 계약을 따른다. 가중치·fallback 가치·가격·XP 배분은 미확정 제안이며 문서 개정은 제품 구현/전투 검증 승인이 아니다.
