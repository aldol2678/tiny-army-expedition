- **궁극 진화는 특정 유물이 필요하지만 일반 원정 완주에는 필요하지 않다.** 유물을 못 뽑으면 완주할 수 없는 구조는 출시 조건을 통과하지 못한다.
- 사운드는 1.0 필수다. 이 문서는 게임 콘텐츠를 다루며 사운드·저장 호환·기기 검증의 세부 출시는 별도 출시 검증안과 함께 승인한다.

### 3.2 기능이 늦어질 때 줄이는 순서

1. 신규 사건의 서사 길이와 보스 변주 수를 줄인다. 경로·보상 규칙은 유지한다.
2. 신규 유물은 **효과 계열째** 줄인다. 이름만 바꾼 불완전 유물로 수량을 채우지 않는다.
3. 궁극의 연출 규모와 고유 외형을 줄인다. 자격·목표획득·비궁극 완주 검증은 줄이지 않는다.
4. 경제 유물과 두 번째 지휘 변형은 다음 버전으로 넘긴다. 지원 직책·파견은 이번 계획의 후속 묶음에도 넣지 않는다.
5. **5장과 확정된3~5장 역할, 2차2기술/3차2+궁극**, 저장 안전성, 설명과 실제 효과의 일치, 소리 제어, 일반 편성의 완주 가능성은 컷하지 않는다.

궁극·연구소가 각각 플레이 선택을 바꾸지 못한다면 ‘1.0에 이름만 넣는 것’보다 범위 재승인을 받는 편이 낫다. 문서 수량은 출시 약속이 아니다.

## 4. 병사 성장: 역할 분기에서 전문화와 궁극까지

### 4.1 성장 구조 제안

**기본4병과 → 기존1차8갈래 → 별도2차 전직(기본 기술2개) → 선택적3차 전직(기존2개+궁극기1개)**

현재 방벽병·돌격병 등8갈래는 계속1차다. 이를2차로 다시 부르지 않는다. 제안 모델은 역할별2차8개 × 특화/운용2운용형이며, 훈련II와 자격/비용을 연계해도2차 단계·기술2개의 실제 동작은 별도로 존재해야 한다. 개별 기술 후보는 [전직·기술 성장 설계](class-skill-progression.md)와 맞춘다.

2차 전문화를 기존 훈련과 별도 비용·경험치로 중복시키지 않는 안을 권장한다.

훈련II를 자격으로 쓰는 것은 **간소화 제안**이다. 사용자 확정은 **2차 전직에 기본 기술2개, 3차에는 그2개+궁극기1개**다. 평타는 별도이며 평타를 기술 하나로 세지 않는다. 기술마다 이름·발동 조건·행동/대상·주기/비용·유물 태그를 정의해야 하므로, 훈련II에 새 이름만 붙여 완료 처리할 수 없다. 16개 조합을 별도 직업·초상화16종으로 제작할지는 미정이다. 아래 정체성 표는 기술2개 명세를 대체하지 않는다.

- 여기서 기본 기술은 병사 고유 기술이다. 플레이어 지휘 기술4종 중2개 장착과 별개다.
- 2차는 열쇠 없이 기술2개가 완성된다. 3차는 부모 역할과 두 기술을 유지하고 궁극기1개를 더하며, 기존 훈련·유물의 대상 태그도 계승한다.
- 기본 기술은 현행 자동전투 운용을 출발점으로 삼는다. 궁극의 자동/수동·충전·횟수는 아직 제안이며 확정된 조작 방식이 아니다.

- 기본 비교안은 **1차 진화 + 훈련I + 훈련II의 성장3선택**이다. 마지막 자격을 충족하는 선택의 같은 거래에서 별도2차 단계와 실제 기본 기술2개를 원자적으로 개방하며, 네 번째 보상 선택·추가 전직 골드는 없다. II를 먼저 얻었다면1차 선택이 마지막 조건이다. 단계는 저장·표시에 따로 남기므로 기존1차 재명명이나 단계 삭제가 아니다.
- 2장의 목표는 주력1명의2차 체험 기회다. 정해진 성장 슬롯은 정원·교대·리롤과 독립적으로 제시하고, 거절했다고 자동 지급하지 않는다. 상세 비용·고정 슬롯은 [5장 원정 설계](five-chapter-run.md)와 [기회·경제 감사](economy-audit.md)를 따른다.
- `type`은 현재12개 ID를 부모 역할로 보존할 수 있다. 다만 `training === 2`만을2차 전직의 표현 전부로 쓰지 않는다. 별도2차 단계/전문화 ID와 기본 기술2개 정의를 저장하고, 훈련II는 그 자격으로 연계하는 제안이다. 3차는 그 위에 궁극기ID를 추가한다.
- 기존 병사 ID, 컨디션, 훈련 경로, 배치, 계열을 보존한다. 전문화가 별도 병사 한 명이나 추가 시너지 인원으로 계산되지 않는다.
- 전문화는 단순히 기존 수치에 새 수치를 계속 곱하는 방식보다 역할의 강점과 공백을 분명히 한다.
- 기존 원정에는 새 효과를 소급하지 않는다. v1.0 새 원정만 새 전문화 규칙을 쓴다.

아래는 정체성 후보다. 개별 계수는 현행 수치와 같은 조건의 비교 후 확정한다.

| 1차 병과 | 특화 II: 잘하는 일 | 운용 II: 다른 선택 이유 | 피해야 할 결과 |
|---|---|---|---|
| 방벽병 | 철벽 지휘: 자신의 생존으로 보호 연결 유지 | 연결 지휘: 인접 보호의 효율을 높여 저체력 아군 보호 | 두 방벽병의 보호를 무제한 중첩 |

### 4.2 궁극 진화 4계열

| 궁극 계열·가칭 | 열쇠 유물 | 계승하는 역할 | 궁극의 핵심 재미 |
|---|---|---|---|
| 불굴의 선봉 | 맹세의 철심 `iron_oath` | 방벽병 또는 돌격병의 기존 행동 | 생존형은 인접 방어의 중요한 순간, 돌파형은 돌격 직후의 버티기 강화 |
| 천공의 명수 | 매의 인장 `eagle_signet` | 저격수 또는 연사수 | 단일 집중/다중 정리 중 고른 방식을 크게 드러내는 사격 |
| 비전의 현자 | 비전의 씨앗 `arcane_seed` | 폭염술사 또는 서리술사 | 피해/제어의 선택을 보존한 제한 횟수의 강화 주문 |
| 생명의 수호자 | 서약의 등불 `covenant_lamp` | 군의관 또는 수호사 | 회복/보호막 중 선택한 지원 역할의 결정적인 구조 |

이 표의 4개는 **궁극 계열 수**다. 이전 병과의 행동을 지워 네 가지 똑같은 최종 병사로 합치는 뜻이 아니다. 부모 병과와 전문화가 다른 16개 진입 조합은 모두 검증한다.

초기 제한 제안:

- 전문화 완성 + 해당 열쇠 유물 소유 + **4장 각성 지점** 도달이 자격이다. 기회는4장 진입 지도 패널이며 별도 합류 재기회는 없다. 이때 각성하면 이후14전투(5장 전체7전투 포함)가 사용 기회로 남는다. 3장 각성안은 폐기한다.
- 열쇠 유물은 **진화 I부터 자격 인정**, 보유만 검사하고 소비하지 않는다. 제련비나 전설 희귀도를 추가 필수 세금으로 요구하지 않는다.
- 원정당 각성 병사 **1명**, 추가 각성비0G부터 시험한다. 새 반복 재화를 만들지 않고 원정의1회 선택으로 표시한다. 인원·비용·발동 방식은 초기안이다. 3차는 기존 기본 기술2개+궁극기1개이며 두 기본 기술을 지우지 않는다.
- 궁극은 전투 시작 편성에 들어간 병사에게만 효과가 있다. 예비에 두면 전투 효과·시너지에는 참여하지 않는다.
- 별도 부활, 공격력 무제한 누적, 재사용 초기화 연쇄는 1.0에 넣지 않는다.
- 궁극 이전의 모집·훈련·2차 기본 기술2개·지휘·배치만으로도 일반 난이도 **5장 완주**가 가능해야 한다.

### 4.3 필요한 유물을 찾을 수 있게 만드는 계약

‘등장 확률을 높인다’만으로는 목표 획득 경로 보장이 아니다.

1. 목표 계열/유물1개를 선택한다. 시작부터 계획을 볼 수 있고, 제안상 늦어도3장 진입 전에 지정한다. 정보만 보는 행동은 무료다.
2. 지도는 정예·상점0회 경로에도 **3장 보스(전체21) 보상의 미획득 지정 목표 슬롯**을 보장한다. 목표는 열쇠 또는 비궁극 핵심 유물이며 기존 한 선택 안의 슬롯을 대체한다.
3. **3장 수집 구간**에 목표 경로를 둔다. 초기안은3장 전투2의 선택 정예 목표 슬롯, 그 뒤 선택 상점 재고, 3장 보스 보상의 마지막 대안이다. 일반전 자체에 목표를 소급 추가하지 않는다. 4장 진입 전에 열쇠를 준비할 기회이며, 한 보상에서 한 개만 선택하고 공짜 추가 유물로 중복 지급하지 않는다.
4. 상점 대안은 표시된 가격과 해당 시드의 최소 획득 가능 골드로 구매 가능성을 검증한다. 연구·회복 등에 먼저 소비한 경우까지 무조건 무상 지급하지는 않는다.
5. 목표 보상은 받기 전 새로고침으로 영구 소실되지 않는다. 새로고침의 고정 슬롯 또는 재제시 규칙을 화면에 명시한다.
6. 이미 목표를 얻었으면 목표를 완료 처리하고 추가 보상은 지급하지 않는다. 이후 목표 슬롯은 생성 시 저장된 같은 예산의 fallback을 따른다. fallback 종류·가치는 미확정이며 새 카테고리 추첨은 없다. 중복 목표 유물을 자동 훈련으로 바꾸지 않는다.
7. 목표 선택은 예비를 포함한 보유 병과를 인정한다. **효과 적용은 출전 기준**이며, 일반 보상 풀은 출전 조건을 유지한다.
8. 플레이어가 목표 경로와 대안을 모두 명시적으로 건너뛰면 미획득이 가능하다. ‘선택 기회 보장’과 ‘자동 획득 보장’을 구분한다.

상태 표시는 ‘목표 지정 → 경로 확보 → 제시됨 → 획득/거절/건너뜀’으로 추적한다. 같은 시드에서 불러오기·패널 열기·교대만으로 경로가 바뀌지 않는다.

## 5. 전술 연구소와 지휘 기술 빌드

### 5.1 최소 연구 규칙

- 4개 기본 기술, 장착 2칸 유지. 기본형은 항상 쓸 수 있다.
- 연구 가능한 기존 서비스에서 장착 기술 하나의 변형을 연구한다. 첫 안은2·4장 각1기회, 방문당1회·비용20G·원정 총2기회다. 5장이라는 이유로 매 장 연구를 추가하지 않는다. 기존 모집/회복/제련을 고려해 조정한다.
- 연구한 형태는 해당 원정에만 보유한다. 지도·준비 화면에서 기본형과 무료 전환, 전투 중 변경 금지.
- 연구소는 모든 경로가 반드시 지나가는 지점으로 만들지 않는다. 무료 직행과 목표 유물의 도달성을 훼손하지 않는다. 필수 보스 전 휴식은 두지 않는다.
- 일반 원정에서 기술 연구 없이도 완주할 수 있어야 한다.

### 5.2 첫 변형 4개

수치는 실측 결과가 아닌 초기 비교안이다.

| 기술 | 현행 기본형 | 1.0 변형 | 얻는 것 / 포기하는 것 |
|---|---|---|---|
| 응급 회복 | 생존 아군 전체 최대 HP 15%, 24초 | 집중 처치: HP 비율이 가장 낮은 생존 1명 최대 HP 35%, 18초 | 한 명 구조 / 전체 회복 포기 |
| 수호 진형 | 4초간 피해 감소 20%, 20초 | 충격 차단: 3초간 35%, 24초 | 큰 예고 공격 대응 / 긴 공백 |
| 집중 사격 | 적 1명, 평타 피해 +10%, 6초, 18초 | 압축 표식: 평타 피해 +25%, 4초, 24초 | 짧은 화력 집중 / 유지 시간·재사용 손해 |
| 사기 고양 | 생존 아군 평타 가속 +25%, 5초, 26초 | 돌격 신호: 창 계열 평타 가속 +40%, 4초, 22초 | 근접 편성 집중 / 다른 계열 가속 포기 |

원거리·마법사 편성은 기본 사기와 다른 연구를 조합할 수 있다. 변형을 모두 사는 것이 상위 정답이 되어서는 안 된다. 1.1에 회복 진지·전열 엄호·연쇄 표식·지속 사격을 비교 후보로 둔다.

### 5.3 계산과 설명 계약

- 변형의 기본값 → 적용 대상이 맞는 유물 합산 → 현재 상한 → 명시적 대가 → 최종 틱 반올림 순서를 데이터로 고정한다.
- 지휘 쿨다운 감소는 **모든 출처 합계 최대 20%**에서 출발한다. 감소율 출처마다 곱해 상한을 우회하지 않는다. 추가 대기 초는 감소 적용 후 더한다.
- 병사 고유 기술 쿨다운과 지휘 쿨다운은 별도다. 마법사의 마나·주문을 지휘 유물이 자동 가속하지 않는다.
- 수호는 최종 피해 감소 55%, 가속은 50% 등 현행 전투 상한을 지킨다. 지속시간이 재사용 시간 이상이 되는 수호 조합은 허용하지 않는다.
- 치유는 초과 회복·부활·컨디션 회복을 만들지 않는다. 치유량 0이면 치유 발동 유물도 작동하지 않는다.
- 집중 사격은 정상 사거리를 넘지 않으며, 별도 표기가 없으면 평타에만 적용한다.
- 연구 설명은 ‘좋아짐’ 대신 대상, 실제 위력, 실제 지속, 실제 재사용, 대가를 현재→변경으로 보여 준다.

대표 빌드:

1. **정밀 대응:** 충격 차단 + 전술 나침반. 수호의 공백을 줄이되 다른 지휘의 대기 시간이 길어진다.
2. **짧은 집중 화력:** 압축 표식 + 묵직한 지휘봉 + 예리한 눈. 표적 처치 후 과잉 화력과 긴 공백이 약점이다.
3. **구조 우선:** 집중 처치 + 구조 매듭 + 군의관. 한 번의 위급 상황에 강하지만 여러 병사 동시 피해에는 기본 회복이 낫다.
4. **교대 전열:** 복귀 휘장 + 돌격 신호 + 돌격병. 쉬고 복귀한 주력의 첫 교전이 강하지만 장기전은 기본 상태로 돌아온다.

## 6. 유물 확장: 72후보·25/11/36 검증 순서

유물별 수치·태그·대가·획득처의 활성 명세는 [유물 대도감](relic-catalog.md) 한 곳에서 관리한다. 구48종 표는 보관본으로 옮겼으며 이 문서에서 중복 계수를 유지하지 않는다.

- 첫25종: 기존17종 + 열쇠18~21 + 배치26~29. 조건부11종은22~25·30~36, 후속36종은37~72다. 합계72이며 출시 확정이 아니다.
- 일반 후보는 현재 출전/지휘 기준, 지정 목표 검색만 예비 포함 보유 전체 기준이다. 실제 전투 효과는 출전과 해당 행동 조건을 만족해야 한다.
- 제시 순서는 카테고리 → 희귀도 → 적격 ID → 사전 고정 fallback이다. 편성·정원·중복·포화로 카테고리나 희귀도를 재추첨하지 않는다.
- 공통 preview는 실효 증가, 모든 대가, 의미 있는 발동 조건, 현재/미래 효용, 남은 이용처, 각성 자격을 분리한다. 양의 수치 하나만으로 유효 판정하지 않는다.
- 34회는 전체 선택 기회이지 유물34개가 아니다. 목표 슬롯·서비스·fallback은 추가 무료 보상창을 만들지 않는다. 가격·가중치·fallback 가치·활성화 정책은 승인/검증 전 미지원이다.
- 기존17종 sanity/고정 조우 관찰은 신규8종 검증이나35전투 완주율 검증을 대신하지 않는다. 검증 범위는 relic-validation/REPORT.md를 따른다.

## 7. 예비대 적체를 줄이는 설계

### 7.1 현재 규칙의 한계

**현재 상한20명은 출전+예비를 합친 전체 보유 인원이다. 예비만20명까지 별도로 쌓이는 규칙이 아니다.** 예를 들어 보유20명 중9명을 출전시키면 예비는11명이다. 출전 인원을 덜 채우면 예비 수는 그만큼 늘지만 전체20명을 넘기지 않는다. 1.0에서도 우선 이 상한을 유지한다.

예비 +6 회복은 ‘지친 주력을 쉬게 하는 기능’이지, 이미 쓸 만한 9명을 완성한 뒤 새 병사를 계속 모을 이유를 보장하지 않는다. 현재 모집 후보는 보유 20명 전까지 계속 생기고, 신규 병사에게 쓴 보상은 주력 훈련·유물 기회를 대체한다. 원정 후반에는 새 기본 병사가 성장할 전투와 상점이 얼마 남지 않는다.

설계 목표는 **20명 전부에게 항상 이익을 주는 것**이 아니다. 소수 정예, 소규모 예비 교대, 특정 적 대비 후보군이 각각 합리적이게 하고 필요 없는 모집을 강요하지 않는 것이다.

### 7.2 1.0 우선안: 세 가지를 먼저 묶는다

**A. 정원 채움으로 성장 확률을 조작할 수 없는 보상 규칙**

사용자가 지적한 ‘20명을 먼저 채운 뒤 특정 병사만 강화’ 문제 때문에 **정원 초과 모집을 무료 훈련으로 전환하는 안은 폐기한다.** 모집 후보를 삭제한 뒤 남은 훈련·진화 후보의 확률을 다시 정규화하는 것도 같은 문제이므로 해결책으로 쓰지 않는다.

- 병사 보상의 모집/훈련/진화와 유물 카테고리의 제시 기회는 정원과 독립적으로 정한다. 보유19→20으로 바뀌었다는 이유만으로 훈련 슬롯·대상 선택권·리롤 기대값이 늘지 않는다.
- 카테고리를 정한 다음 해당 카테고리의 적법한 후보를 찾는다. 불가능한 모집 자리를 훈련·유물·골드로 자동 승격하지 않는다.
- 전투당 한 보상 원칙을 유지한다. 무효 슬롯을 메운다는 이유로 다른 보상을 추가로 지급하지 않는다.
- 특정 병사에 집중 투자하는 빌드 자체는 허용한다. 정원을 채워 보상 분포를 유리하게 바꾸는 수단을 차단하는 것이 목적이다.
- 현재 훈련 상한은 II로 유지한다. 반복 훈련 확대·점감·비용 상승은 별도 밸런스 검토 후보이며 이 문제를 해결했다고 가정하지 않는다.

**정원20명에서의 안전한 처리 원칙과 미결 UI**

| 현재 상태 | 허용되는 처리 | 금지되는 자동 대체 |
|---|---|---|
| 보유19명, 모집2명 후보 | 현재처럼 남은1명 자리만큼 모집 | 남은 한 명분을 훈련/골드로 환산 |
| 보유20명, 모집 카테고리가 뽑힘 | 모집 불가를 명확히 표시하고 원래 제시된 다른 카테고리 또는 스킵 선택 | 모집 삭제 후 훈련으로 재추첨·확정 전환 |
| 훈련 카테고리가 뽑혔고 훈련0/I 대상 있음 | 해당 카테고리의 원래 규칙으로 적법한 대상 선택 | 정원20일 때만 더 넓은 대상 선택권/추가 단계 지급 |
| 전원훈련II | 훈련 불가 표시. 원래 제시된 다른 선택 또는 통과 | 훈련III 생성, 무료 진화로 전환 |
| 현재 후보가 마음에 안 듦 | 현행1회5G 새로고침/전체 스킵을 유지하되 카테고리 분포는 정원과 무관 | 자동 차감, 정원20 전용 유리한 리롤·무료 리롤 |
| 모든 제시가 불가능하고 대체 가능한 합법 후보도 없음 | 이유를 알리고 비용 없이 통과 | 효과 없는 유료 리롤, 불가능한 수령 강제 |

이 처리만으로 ‘쓸 수 없는 보상을 받는 불쾌함’이 해결됐다고 보지는 않는다. **후보 A:** 카테고리 슬롯을 정원과 독립적으로 뽑고 불가 슬롯을 비활성 표시. **후보 B:** 모든 인원수에 같은 고정 카테고리 구성을 제시하고 선택은 한 번만 허용. A는 확률 선택, B는 예측 가능한 선택이 장점이지만 둘 다 정원 포화 시 사용 불가 선택이 생길 수 있다. 어떤 구성을 채택할지 사람 플레이와 기대가치 비교 후 결정한다. 새 재화나 직책을 만들지 않는다.

현행 `_troopCandidates`는 보유20명에서 모집 후보를 제외하고, `_makeReward`는 남은 병사 후보를 섞는다. 따라서 **현행 유효 후보 필터를 그대로 재사용하면 확률 조작까지 방지된다고 주장할 수 없다.** 1.0에는 카테고리 추첨/제시와 후보 자격 필터의 순서를 별도로 설계해야 한다.

자동 해고·자동 합성·자동 골드 환전은 하지 않는다. ‘현재 병사를 내보내고 새 병사를 영입’하는 교체 영입은 플레이어가 대상을 직접 고르고 확인하는 **별도 후속 검토**로만 남긴다. 정원 초과를 막기 위해 기존 병사를 조용히 삭제하지 않는다.

**B. 교대가 필요한 이유를 전투 전에 이해하게 한다**

- 다음 작전에 ‘다수 잔병 / 방어 전열 / 긴 사격 / 겹친 강타’ 압박을 표시한다.
- 다중 공격, 단일 집중, 방벽, 치유가 각각 유리한 구간을 만든다. 특정 병과가 없으면 통과 불가능한 하드 카운터는 넣지 않는다.
- 교대 미리보기에서 출전 정원, 2/4 시너지 변화, 방벽 연결, 활성 유물, 예상 컨디션 회복 대상을 보여 준다.
- 전투 중 교대는 추가하지 않는다. 지도·준비에서 되돌릴 수 있는 선택을 유지한다.

**C. 예비를 쉬게 해도 목표 준비는 가능하게 한다**

- 일반 랜덤 유물은 출전 기준을 유지한다.
- 명시한 목표 유물 검색은 예비 포함 보유 병과를 인정한다. 쉬는 마법사를 위해 마법 목표를 추적할 수 있다.
- 예비 유물의 실제 전투 효과는 여전히 없고, 목표 표시와 효과 활성 표시는 분리한다.
- 복귀 휘장은 단순히 넣었다 빼는 동작이 아니라 **이전 승리 당시 예비였음**을 요구한다.

### 7.3 최신 결정: 별도 직책 없이 교대 화면을 개선

별도 파견·정찰·보급·응급지원 직책은 이번 설계에서 제외한다. 예비대 문제를 새 메뉴와 관리 의무로 해결하지 않는다.

- 기존 편성 화면에서 다음 적의 압박, 병사의 컨디션, 교대 전후 시너지·유물 효과를 함께 비교한다.
- 교대 자체는 무료이며 준비 화면에서 되돌릴 수 있다. 배치 변경 횟수가 재화나 추가 보상을 만들지 않는다.
- 휴식 효과는 현재처럼 실제 전투 시작 때 예비였던 병사가 승리했을 때만 적용한다.
- 교대 유물도 이 기존 기록만 사용한다. 별도 교대 경험치·근무 피로·보급 포인트를 추가하지 않는다.
- 소수 정예로 계속 출전하는 선택도 유지한다. 교대 유물이 필수 구매가 되면 해당 유물을 줄이거나 후속으로 넘긴다.

### 7.4 피할 해법과 검증 기준

- 모든 예비 한 명당 공격력·골드·시너지 증가: 20명 채우기가 정답이 되므로 제외.
- 심한 부상·피로를 강제해 매 전투 교대: 불쾌한 관리가 목적을 대신하므로 제외.
- 병사를 소모해 영구 능력치를 올리는 해체: 소유권·보상 경제·취향 리스크가 커 후속 별도 승인.
- 같은 예산으로 예비0~2 정예형, 예비3~5 교대형, 보유20 적체형을 비교한다. 예비0도 보상 선택과 완주가 유효해야 한다.
- 측정: 후반 모집 선택률, 실제 교대된 병사 비율, 한 번도 출전하지 않은 인원, 선택 가능한 유효 보상 비율, 편성 시간, 반복 피로도. 예비수가 많다는 사실만 성공 지표로 삼지 않는다.

### 8.3 보스 변주 초기안

- 평원: 현재 넓은 강타·잔병 호위에 더해 ‘분산 호위’ 변주를 둔다. 다중 공격이 도움이 되지만 단일 집중으로 호위부터 줄이는 길도 가능하다.
- 철성: 현재 겹친 강타·사격 압박에 더해 ‘교대 강타’ 변주를 둔다. 수호 타이밍을 읽는 선택과 전열 분산의 선택을 제공한다.
- 변주를 체력·공격력 배수만으로 구분하지 않는다. 예고, 적 구성, 공격 주기, 대응 가능한 수단이 달라야 한다.
- **5장 각각 보스 조우1회·장별 프로필5개**가 필요하다. 3장 수집 경로에 맞는 위험 선택, 4장 궁극을 시험할 압박, 5장 이미 배운 압박의 조합을 설계한다. 에셋 재사용은 가능하나 이를 신규 고유 보스5종으로 홍보하지 않는다. 구체 패턴·신규 에셋 수는 승인 전 제안이다.

## 9. 증표와 해금

증표는 다음 원정의 **선택지**를 연다. 전투 패배를 반복해 영구 공격력을 구매해야 하는 구조로 만들지 않는다.

- 기존 유물·갈래·훈련·전술 해금과 보유 증표를 보존한다. 이번 원정 earnedTokens와 지출 가능한 profile.tokens를 분리하고 종료 때 한 번만 합산한다. 제안 안전 완주80증표는 현행 유료 해금10개 총74를 넘어 **완주1회당 구매력**을 키우지만 자동 해금은 아니다. 기본 전투 수도8→35로 늘므로 완주당 증표를 시간당 해금 속도로 해석하지 않는다. 80증표도 옛 경제안의 예시이며 새35전투 수입을 확정하지 않는다. 완주당·분당·퇴각당 수입을 나눠 검증한다.
- 새 연구 변형, 추가 유물군, 선택형 시작 전술, 추가 전문화 설명/도전 목표를 해금 후보로 둔다.
- 기본 4병과, 기존 무료 갈래, 기본 지휘 기술, 일반 완주에 필요한 수단을 새로 잠그지 않는다.
- 궁극 연구를 해금할 때 해당 열쇠의 목표 경로도 함께 자격을 연다. 궁극 자격은 샀는데 열쇠만 잠겨 실현 불가능한 상태를 만들지 않는다.
- ‘해금’은 다음 원정 후보/선택권을 여는 행위다. 병사·유물 실물이나 골드를 즉시 지급하는 것과 구분한다.
- 시작 전술은 병과 조합을 바꾸는 선택으로 유지한다. 새 직업 해금은 해당 직업이 실제 제작·검증된 후에만 등록한다.
- 비용은 현재 증표 수입·첫 성공까지의 시간·기존 자격을 유지한 테스트 후 확정한다. 이 문서는 새 증표 가격표를 확정하지 않는다.

## 10. 데이터 설계 제안

실제 코드가 아니라 콘텐츠·캠페인·전투·UI가 합의할 계약 초안이다. 새 문자열과 스키마 번호도 구현 시 확정한다.

### 10.1 정의 데이터

| 정의 | 필요한 필드 | 핵심 불변식 |
|---|---|---|
| `SpecializationDef` | id, parentType, progressionStage, trainingTrack, requiredTraining, family, displayName, basicSkillIds[2], actionOverrides, modifiers, rulesVersion | 부모 역할·계열 유지, 훈련 II에만 활성, 보너스 재귀 중첩 금지 |

| `SkillVariantDef` | id, baseSkillId, targetRule, cooldown, duration, effectFields, exclusions, unlockId | 기본형을 덮어쓰지 않음, 같은 기본 기술의 변형 하나만 활성 |

### 10.2 원정 상태

- `rulesVersions`: 콘텐츠/전투/지도/보상/저장 버전을 명시한다. 새5장 정의와 장별 목적·보상 계획을 저장하며, 구버전 원정은 원래2장 정의로 끝낸다. 현재 장1~2·지도32노드·2장완주·bestChapter 검증을 새 버전에서 함께 확장한다.
- `research`: 연구한 변형 ID, 장착 기본기술별 선택 형태, 연구 거래 영수증.
- `ultimate`: 각성한 병사ID, 부모 병과/전문화·기본 기술2개, 궁극기ID, 자격 유물, 4장 각성 기회 상태·확정 노드·영수증. 3차에서도 기존 유물·훈련 연결을 보존한다.
- `targetAcquisition`: 지정 목표, 계획 ID, 고정된 기회 목록, 제시/획득/거절 상태.
- `rotationEligibility`: 기존 예비 회복 원장 또는 전투 기록에서 파생한 복귀 자격. UI 토글로 새 자격을 생성하지 않는다.
- `transactions`: 연구·각성·제련·보상 선택은 원정 ID/노드 ID/현재 revision/후보 ID를 검사한 뒤 한 번만 반영한다.
- 임시 전투 버프, 실제 피해, 전투 중 소리 재생 상태를 영구 프로필에 누적하지 않는다.

### 10.3 효과 계산에서 분리할 대상

1. 후보 등장 조건: 일반은 출전, 지정 목표는 보유 전체.
2. 시작 편성 조건: 계열 수, 시작 열, 상하좌우, 소수 전열.
3. 행동 조건: 평타/강화탄/병사 고유 기술/지휘/정상 치유/보호막.
4. 발동 조건: 성공한 실제 행동, 대상의 행동 전 상태, 횟수 제한.
5. 정산 조건: 승리, 전투 시작 예비, 최초 완료, 해당 노드 영수증.

이 다섯 가지를 단일 ‘활성 유물’ 불리언으로 뭉치면 예비·사망·새로고침·재접속에서 오류가 생긴다.

### 단계 D: 모집/교대와 원정 다양화

- 정원과 독립된 보상 카테고리, 교대 전후 시너지/유물 설명, 사용 불가 선택의 빈도·불쾌함 확인.

## 12. 확정 전에 필요한 결정

1. **2차 전문화 구현:** 기본 기술2개는 확정. 훈련II와 결합할지·16조합의 기술 명세와 에셋을 어떻게 간소화할지는 결정 대기다. 평타를 기술로 세지 않는다.
2. **궁극 수량:** 4계열·원정1명부터 시험할지, 원정당 여러 명을 허용할지. 권장 출발점은 전자다.
3. **유물 컷:** 후보72 보존, 첫25 검증·조건부11·후속36. 출시 수량은 미확정이다. 시각 자산·효과 검증이 늦으면 효과군 단위로 줄인다.
4. **예비 개선 범위:** 별도 직책 없이 교대·컨디션·보상 개선에 집중하는 것으로 방향을 고정한다. 교대 유물은 실제 적응형 교대보다 반복 교체를 유도하면 컷한다.
5. **원정 세부 예산:** 5장과3수집/4궁극/5활용은 확정. 장당 최소7전투의 보스 포함 해석, 기본35전투·34보상·서비스0~2/장·XP3/1/1/1/1/2/1·4장 진입 각성의 비용/한도·자동/수동 발동은 제안 또는 명시적 해석이다. 플레이 시간은 미실측이다. 장 수를 다시2로 줄이는 선택지는 아니다.
6. **경제 유물:** 남은 원정의 제련 손익과 환급 악용까지 검증한 뒤 도입한다.

사기/컨디션 분리, 암살자/공병, 전투 중 교대, 영구 능력치 무한 성장, 자동 병사 해체는 이번 권장 MVP에 포함하지 않는다.
