# 꼬마 군단 원정대 1.0 유물 대도감 설계

작성: 2026-10-18 UTC. **총 72종 보존: 첫 검증 25종 + 조건부 다음 검증 11종 + 후속 후보 36종.** 기존 일반 획득 17종을 포함한 총수이며 신규 아이디어는 55종이다. 이름만 다른 공격력 유물을 늘리기보다 배치, 행동 시점, 자원, 구조, 표적 수, 교대, 경로 선택의 차이를 만든다.

이 문서는 설계 산출물이다. 신규 유물을 게임에 구현하거나 배포하지 않았고, 신규 수치의 전투 밸런스는 검증하지 않았다. 72종 동시 출시를 권하지 않는다. 기존 `content-plan.md`의 48종 후보는 모두 보존하되 아래에서 모호한 조건과 상한을 구체화했다. 본 문서의 신규 24종은 추가 제안이며, 기존 기술 실행 계약을 덮어쓰는 승인이 아니다.

## 1. 바꾸지 않는 중심 구조

- 원정은 5장. 모든 적법한 경로에서 장당 최소7전투(보스 포함 해석), 기본 생성안은 정확히35전투다. **3장 유물 수집 → 4장 궁극 진입 → 5장 활용**을 유지한다. 전투1~34의34보상 기회와 XP3/1/1/1/1/2/1은 미확정 제안이며 최종35는 정산만 한다. 선택 서비스는 전투를 대체하지 않고 별도 합류·빈 대기방을 만들지 않는다.
- 2차는 평타와 별개의 고유 기술 2개, 3차는 그 2개 + 궁극기 1개다. 유물은 기술 칸을 대체하거나 기존 기술을 삭제하지 않는다.
- 기본 병과 → 1차 역할 → 2차 → 3차로 가도 같은 병사 ID, 부모 계열, 역할 태그, 훈련 투자와 유물 자격을 보존한다.
- 특정 유물·전설·궁극·특정 직업이 없으면 진행할 수 없는 문은 만들지 않는다. 열쇠는 선택적 궁극의 자격이며 일반 완주의 필수품이 아니다.
- 기존 중복 ID 불가, 유물 슬롯 제한 없음, 고유 희귀도 고정, 제련 I/II/III를 출발점으로 삼는다. 새로운 중첩 슬롯 시스템은 추가하지 않는다.

## 2. 코드로 확인한 기준과 표 읽기

근거 파일은 `tiny-army-sites/dist/js/v09-content.js`의 CAPS(14행), RELICS(76~95행), FIELD_CAPS(135행), collectModifiers/projectUnit/forgePreview와 `game-engine.js`의 피해·행동 처리다. 행 번호는 이번에 읽은 작업 트리 기준이다. 과거 v0.8의 중복 유물·희귀도 배율은 사용하지 않는다.

### 공통 획득·계승·난도 표기

- 획득 `기본`은 새 영구 해금 없이 자격을 만족한 보상·상점 후보. `기존 해금`은 기존 증표 해금을 그대로 유지. `목표`는 3장 지정 탐색, 목표 정예 또는 안전 경로의 3장 보스 대안에서 선택 기회 제공. 모두 **실물 자동 지급 아님**.
- `연구/배치/야영/치료/보급`은 관련 사건·서비스에서 후보를 제시하는 새 제안. 추가 무료 보상이나 새 노드 지급을 뜻하지 않는다. 기존 한 번의 선택 예산 안에서 교체한다.
- `후속`은 해당 기능이 출시되어야 획득 가능. 필요한 사건·상태이상 체계가 없으면 잠긴 실물 카드도 내보내지 않는다. 신규 유물의 영구 해금은 우선 불필요하며 도감 발견만 남긴다.
- 계승 `전원` = 모든 출전 병사의 전직 뒤 동일 적용, `계열` = 창/궁/마법/지원 부모 계열 유지, `역할` = 해당 1차 갈래 유지, `행동` = 동일 행동 태그만 유지, `배치` = 전투 시작 칸 조건 유지, `지휘` = 지휘에만 적용, `원정` = 병사 전직과 독립. 예비는 전투 효과 제외.
- 난도 `낮음`은 기존 투영 필드/필터 중심, `중간`은 새 조건·카운터·저장 항목, `높음`은 시간 예산·이벤트 원장·여러 대상/화면 변경이 필요하다는 상대 평가다. 낮음도 무검증 출시 가능이라는 뜻은 아니다.
- 수치는 별도 설명 없으면 **I / II / III**의 최종값이다. `%p`는 확률의 퍼센트포인트. HP 비율은 최대 HP 기준, 피해량은 별도 표시 없으면 해당 원 행동의 값 기준이다.

## 3. 상한 때문에 죽은 유물을 만들지 않는 정책

1. 상한 초과를 보호막·골드·궁극 충전으로 바꾸지 않는다. 양의 효과는 같은 버킷에서 합산·상한 적용한 뒤 대가를 별도로 적용한다.
2. “양의 능력치 하나 존재”는 순이득 판정이 아니다. 동일 편성·배치·훈련·지휘·컨디션에서 미보유/보유 또는 제련 전/후를 비교하여 실제 증가와 손실을 함께 반환한다. 서로 다른 AP·마나 재생·응답시간을 근거 없이 단일 점수로 합치지 않는다. 순수 개선, 조건부 교환, 무효, 미래 전용을 구분하고 조건부 교환을 ‘추천 순이득’으로 표시하지 않는다.
3. 공통 preview 계약은 보상·상점·제련·도감·목표 탐색에서 동일한 계산을 쓴다: 대상 ID/시작 칸, 원 수치, 상한 뒤 실효 변화, 모든 대가, 발동 조건·현재 충족 여부, 공개 경로상 남은 이용처, 현재 효용/미래 활용/각성 자격, 차단 사유, 비교 기준과 규칙 버전. 미확정 전투 결과를 실제 발동률·승률로 표시하지 않는다.
4. 조건형은 합법적이고 의미 있는 발동 가능성이 있어야 한다. 현재 없는 행동/병과, 남은 경로에 없는 서비스, 끝난 각성 기회를 ‘언젠가 가능’으로 포장하지 않는다. 첫 유물은 현재 출전에서 작동하는 후보만. 일반 보상은 현재 출전/지휘의 유효 효과 또는 공개된 도달 가능 조건이 있는 후보만, 목표 탐색은 보유 전체의 예비 육성·미래 활용을 별도로 허용한다. 예비 전용이면 누구를 어떻게 투입해야 하는지 명시한다.
5. 제련은 실효 증가0이면 차단한다. 일부 증가와 고정 대가가 남으면 둘 다 보여 주고 별도 확인한다. 열쇠 I의 각성 자격은 능력치 상한에서도 별도 가치일 수 있으나 II/III는 자격을 추가하지 않는다. 4장 진입 각성 기회 종료 뒤 자격만 남는 열쇠는 일반 후보에서 제외한다. 미래 활용의 경고를 무효 제련 허용 근거로 사용하지 않는다.
6. 편성 변경으로 비활성화된 기존 보유 유물은 삭제·자동 변환하지 않는다. 해당 유물이 다시 작동하는 병사/배치와 대가를 안내한다. 선택적 비활성화는 아래 안전 정책이 승인·구현된 이후에만 지원한다.
7. 후보 부족은 §8의 사전 고정된 예산 내 fallback으로 처리한다. 편성으로 적격 ID를 없앤 뒤 모집/성장/유물 카테고리를 다시 뽑는 악용은 금지한다.

### 상한과 대가 미리보기의 필수 예

같은 중열 마법사에게 비전 렌즈 III +23%와 중열 공명석 III +24%가 있으면 AP 증가 합은47%다. 과충전 핵 I의 명목 +28%를 더해도 50% 상한 때문에 실제로는 **+3%p(기본 AP 대비)**만 늘며 마나 재생은 그대로 ×0.8, 즉 −20%다. 현재 AP 대비 증가는1.50/1.47−1≈2.04%일 뿐이다. 마나 재생 손실을 상한으로 지우거나 +28% 순이득 카드로 표시하면 실패다. 개막 한 번의 주문과 긴 마나전의 결과가 다를 수 있으므로 실제 순효과는 해당 조우 시험으로 확인한다.

### 선택적 비활성화 안전 정책 (신규 제안, 미승인·미구현)

대가·정책 변형 유물의 획득 거절은 항상 가능해야 한다. 보유 후 비활성화는 다음 전투 전 준비 화면에서 양의 효과·대가를 함께 끄는 안을 검토한다. 전투 입장에 활성 집합을 고정·저장하고 전투 중/일시정지/재접속에서는 변경하지 않는다. 비활성화로 마나·HP·행동CD·궁극권·환급/경제/교대 카운터를 복구하거나 이미 얻은 이익을 중복 수령할 수 없다. 열쇠 비활성화와 이미 완료된 각성의 관계는 별도 승인 전 확정하지 않으며, 현 단계에서는 열쇠 토글을 제공하지 않는 보수적 안이다. 변형55·56·63은 이 정책과 상호배타적 변형 선택 UI가 검증되기 전 채택하지 않는다. 전투 중 무료 토글은 제안하지 않는다.

경제 제련의 평가는 전체 수입이 아니라 같은 남은 경로에서 ‘업그레이드 후 추가 수입/절약 − 미업그레이드 추가 수입/절약 − 실제 제련비’다. 이미 지급한 금액은 양쪽에서 동일하게 차감하고 한도·할인 중첩·최소 결제·방문당1회·지갑·향후 사용 가능한 시점·대안 구매를 반영한다. 상한상 한계 이득조차 비용 이하이면 차단한다. 양수인 최대치도 실제 방문/구매를 보장하지 않으므로 조건부 범위로 표시한다. 마지막 지출 이후 얻는 금액은 원정 구매 가치로 세지 않는다. 남은 유효 이용처가 없는 경제 유물을 제시하지 않고 거래 직전 다시 검사한다.

## 8. 획득 흐름과 보상풀 관리

### 장별 역할

1. **1장:** 기본 병사와 역할 이해. 일반·고급 중심, 첫 유물은 현재 출전에서 작동하는 후보만. 해금되지 않은 기능 설명 카드를 보상으로 내지 않는다.
2. **2장:** 2차 두 기술을 체험. 새로운 고유 기술이 평타·정상 치유 유물을 무효화하는지 확인하는 구간이다. 병과 특화 유물은 선택 가능하지만 필수 아님.
3. **3장:** 유물 수집의 중심. 일반 풀과 분리된 목표 검색으로 열쇠 또는 비궁극 핵심 유물을 지정. 위험 정예 경로와 안전 보스 대안 모두 선택 기회 확보. 목표를 확정한 뒤 무작위 다른 열쇠만 내미는 것은 금지.
4. **4장:** 자격 충족자가 원하면 궁극 진입. 각성은 자동이 아니며 4장 진입에서 명시적으로 선택한다. 각성0G/1명·열쇠20G는 미확정 비교안이고 유료안이면 구매·제련과 같은 예산에서 경쟁한다. 열쇠 미선택 편성은 일반 성장/유물 경로를 유지.
5. **5장:** 이미 모은 것을 사용. 남은 이용처 없는 할인·야영·각성 자격 유물은 일반 후보에서 빼고 즉시 쓸 수 있는 선택만 제시한다.

### 35전투·34보상 기회의 획득 계약 (제안)

34회는 유물34개가 아니라 전투1~34 뒤 각각 한 번의 선택 기회다. 모집/성장/유물의 선택 예산을 공유하며 별도 무료 열쇠·서비스 보상을 더하지 않는다. 최종35는 정산만 한다. 목표 슬롯은3장 보스(전체21) 보상 안의 기존 한 슬롯을 대체하며, 정예·상점0회 경로에도 접근 가능하다. 3장 전투2 뒤 선택 상점은 실제 방문·지갑·재고 조건을 만족해야만 구매하며 추가 지급이 아니다.

제시기 순서는 반드시 **카테고리 → 희귀도 → 적격 ID → 사전 고정 fallback**이다.

1. 원정 seed·규칙 버전·보상 노드·슬롯·승인된 리롤 순번을 키로 카테고리와 희귀도를 결정·저장한다. 카테고리/희귀도 가중치, 슬롯 수, 리롤 가격은 미확정 파라미터다. 테스트용 숫자는 별도 프로필로만 기록한다.
2. 카테고리는 출전 편성/보유20명/유물 포화율에 따라 재추첨하지 않는다. 희귀도도 적격 ID 수에 비례해 다시 뽑지 않는다. 해당 단계가 고정된 뒤 §3의 공통 preview로 현재 출전·지휘, 중복 ID, 해금, 상한, 의미 있는 조건, 남은 이용처를 검사한다.
3. 동일 카테고리·희귀도 안에서 저장된 후보 순열을 따라 적격 ID를 고른다. 결과와 제외 이유·입력 편성 snapshot·preview 버전을 저장한다. 화면을 연 뒤 편성 변경·재접속으로 새 후보를 뽑지 않는다. 선택 직전 자격이 바뀌면 재검사하되 새 카테고리/희귀도 추첨은 하지 않는다.
4. 적격 ID가 없으면 보상 생성 때 저장한 fallback을 소비한다. 보수적 제안은 같은 예산 안의 사전 명시된 범용 대안 또는 패스이며, 대안 종류·가치·수량은 아직 승인되지 않았다. 무효 카드 삭제로 빈 슬롯을 무제한 성장/모집/고급 재화로 바꾸지 않는다. fallback의 가치 상한과 토글로 얻는 우위가 검증되기 전 제시기를 출시하지 않는다.
5. 유료 리롤도 같은 전체 선택 예산·저장 원장을 사용한다. 편성 조작·포화·고유 중복으로 무료 리롤이나 카테고리 승급을 얻지 못한다. 목표 슬롯은 일반 추첨과 분리하여 목표 미획득 열쇠/비궁극 핵심 선택 기회를 유지하고, 목표를 거절하면 자동 지급하지 않는다. 이미 목표를 보유했거나 미래 효용이 없으면 고정 fallback 규칙을 따른다.
6. 보상 확정·지출·수령은 원정ID/노드ID/슬롯ID/revision 기반 하나의 멱등 처리다. 선택 하나가34기회를 넘는 추가 보상창이나 모집 초과분 환급을 만들지 않는다. 19명에서 모집2명은1명 수용·초과 무보상이라는 현행 후보안을 유지한다.

일반 후보의 적격성은 편성에 영향을 받지만 카테고리 확률과 희귀도 확률은 영향을 받지 않는 것이 핵심이다. 편성0명, 계열 부재, 전원 포화, 보유20명, 모든 동급ID 보유, 저장/복원, 목표 거절, 마지막 사용처 종료를 별도 적대적 fixture로 검증해야 한다. 현재 문서는 이 제시기를 구현·검증했다고 주장하지 않는다.

### 유물이 많아져도 길을 잃지 않는 규칙

- 도감은 기능 태그로 검색: 전열 유지, 평타, 주문 자원, 구조, 배치, 지휘, 교대, 경제. 희귀도순만으로 추천하지 않는다.
- 보상 UI는 한 후보당 “대상 / 지금 실제 변화 / 대가 / 미적용 이유”를 먼저 보인다. 세부 계산은 접어서 제공한다.
- 일반 보상 후보군은 현재 출전/지휘 기준, 목표 검색은 보유 병사 전체 기준. 후보 수가 늘어도 예비 마법사 때문에 모든 일반 보상에 마법 유물이 끼지 않게 한다.
- 목표 탐색은 기본적으로 동일 ID 미보유만. 보유 유물의 제련은 대장간 경로로 분리한다.
- 신규 드롭 가중치 숫자는 아직 정하지 않는다. 실제 장별 획득률·목표 도달 비용을 모델링하기 전에 “72종 균등 추첨”을 적용하지 않는다.
- 영구 해금은 선택 폭을 여는 장치로만 사용한다. 기존 무료 유물을 재잠그지 않고, 목표 열쇠를 영구 증표 구매와 원정 추첨의 이중 장벽에 두지 않는다.

## 9. 세 가지 독립적인 완주 후보 경로

다음은 **플레이 검증 대상 빌드**이지 완주가 입증된 조합이 아니다. 이름이 나온 특정 병과가 필수라는 의미도 아니다. 같은 전투 문제를 적어도 두 다른 역할 조합으로 해결하는 것을 출시 조건으로 삼는다.

| 경로 | 핵심 선택 이유 | 예시 유물 | 대체 편성·대응 | 약점과 검증 |
|---|---|---|---|---|
| A. 지속 생존과 교대 | 전열 유지, 작은 손실 회복, 컨디션 관리 | 깃발·연결 핀·천막 또는 식량·구급낭 | 여러 전열+정상 진료, 또는 전열+방호+지휘 회복. 정상 진료 없으면 구급낭 대신 배치 생존 | 긴 전투를 버텨도 화력 부족 가능. 광역에는 밀집 해제, 보호막 빌드도 별도 비교 |
| B. 짧은 집중과 표적 제거 | 한 위협을 빨리 줄이고 다음 위협으로 전환 | 칼날·예리한 눈·지휘봉·빈 측면 또는 조준경 | 창 중심, 궁 중심, 혼합 평타. 강화탄/일제에 치명 유물 무효이므로 일반 평타 기여 확인 | 과잉 피해·잔병·지휘 공백. 광역 역할이나 기본 집중 사격으로 대체 가능 |
| C. 자원 순환과 유연 배치 | 여러 번의 주문·지원 행동을 안정적으로 연결 | 렌즈 또는 공명석·씨앗·잔향·나침반 | 피해 주문+전열, 제어 주문+평타, 지원 AP+지휘 운용. 마법 없는 경우 AP/회복 지휘 중심으로 별도 비교 | 개막 폭발 부족·마나 소진·지원만 남는 상황. 특정 마법 갈래를 강제하지 않음 |

세 경로 모두 열쇠0·전설0·궁극0 대조군을 둔다. 궁극이 있으면 4·5장에 선택한 역할의 활용이 달라져야 하지만, 없는 경로가 구조적으로 막혀서는 안 된다. 유물 3개 세트가 모여야 발동하는 세트 보너스는 도입하지 않는다.

## 10. 공통 구현 계약: 유물 수보다 먼저 지킬 것

- 이벤트는 `rootActionId / eventId / sourceKind / actionType / family / branch / startSlot`을 가진다. 유물 파생 피해·회복·보호막은 다른 유물의 발동 원인이 되지 않는 것이 기본값이다. 예외는 개별 계약과 교차검증 승인 없이는 금지한다.
- 직접 피해, 정상 치유, 특수 수술, 보호막, 지휘 회복, 전투 후 컨디션은 별개다. AP라는 이유로 모두 같은 치유 발동을 공유하지 않는다.
- 다중 표적은 원 행동1회. 탄·잔불 틱·궁극 압축으로 잔향 성공 카운터를 여러 번 올리지 않는다. 실제 마나 지불액, 성공 resolve와 환급 처리 여부를 저장한다.
- 같은 조건·같은 틱의 대상 선정은 기존 우선순위 뒤 거리→안정된 ID로 결정한다. 배열 순서·일시정지·재개로 결과가 달라지면 실패다.
- 미발동 조건이면 비용 미소비. 확정 후 취소는 기존 기술 계약의 비용을 유지한다. 유물로 공격CD·마나·궁극권을 복구하는 숨은 예외를 만들지 않는다.
- 보호막은 큰 잔량만 교체, 같은 크기로 지속 리셋 금지. 초과 치유·피해·사거리 밖 표적·시간 종료 예산은 폐기한다.
- 신규 변형 유물 55·56·63은 기본 기술의 정체성을 바꾸지 않고 정해진 피해/대상 우선순위만 바꾼다. 자동으로 부여하지 않으며 §3의 안전한 비활성화 정책이 승인·검증되어야 한다. 동일 행동에 변형 정책이 여러 개 걸리면 하나만 선택하는 UI와 미적용 사유를 제공한다. 이 UI가 없으면 해당 유물을 출시하지 않는다.
- 공격형 병사를 치유 전용으로 바꾸거나 지원병의 치유를 삭제하는 강제 변환, 회복 불가·평타 불가 같은 빌드 파괴 저주는 이번 후보에 없다.
- 신규 룰은 새 1.0 원정에만. 기존 원정은 기존 규칙으로 재개하며, 새 ID를 구버전 세이브에 무단 주입하지 않는다.

## 11. 검증 체크리스트와 출시 선택

아래는 신규 유물의 테스트 계획이다. 별도 [독립 검증 보고서](relic-validation/REPORT.md)는 기존17종의1,836회 투영 sanity 검사와 기존 조합의512회 고정 조우를 실행했다. 신규8종은 미구현이므로25종 전체 통과나35전투 캠페인 승률을 검증한 것이 아니다.

### 기능·상속

- 기존 17종 효과와 해금 불변, 일반 풀18번째로 실험 유물이 섞이지 않음.
- 8개 1차 갈래×2차/3차에서 태그·유물·훈련 유지, 궁극 효과에 같은 보너스 2회 적용 없음.
- H/A/P 50%, B/N/S/M35%, R55% 바로 아래·동일·초과에서 실제 UI와 전투 원장 일치.
- 공속·CDR·초 단축·고정 대가·후딜 부채를 순서대로 확인. 서로 다른 이름의 가속이 상한을 우회하지 않음.
- 유물 I→II→III, 포화 제련 차단, 일부 적용값, 조건 미충족 이유, 열쇠 자격만 남는 경우 분리 표시.
- 정상/특수 치유, 직접/파생 공격, 시전자 사망, 대상 사망, 전투 종료, 완전 흡수, 초과 치유, 보호막 교체/자연만료 각각 확인.
- 저장/불러오기 후 환급·회복·골드·재추첨·각성 자격·교대 소비의 중복 없음.

### 밸런스·사용성

- 같은 시드·동일 비용으로 A/B/C 비교. 승률뿐 아니라 피해 집중, 행동 점유, 마나 고갈, 컨디션, 첫 발동 시각, 미발동률, 제련 손익을 기록.
- 짧은 일반전/긴 보스전/분산 적/광역/후열 급습/마나전/보호막 적을 분리. 조건형 유물을 조건 없는 조우에서 항상 유리하게 만들지 않음.
- 1장/3장/5장 획득을 비교. 늦게 얻은 경제 유물과 자격 유물의 실제 가치0 카드가 일반 보상에 나오지 않음.
- 유물0·열쇠0·전설0·궁극0 대조군, 서로 다른 병과 대체군으로 완주 가능성 평가. 현재 문서는 결과를 보장하지 않음.
- 모바일 카드에서 첫 화면에 대상·수치·대가가 읽히며, 설명을 열지 않아도 상한에 막혔다는 것을 알 수 있어야 함.

### 승인된 검증 순서와 채택 게이트

1. 첫 검증25종 = 기존01~17 + 열쇠18~21 + 단순 배치26~29. 기존17 회귀를 먼저 확인하고 신규8의 실효 변화·계승·획득·설명을 비교한다. 25종 출시 또는 수치 승인을 뜻하지 않는다.
2. 조건부 다음11종 = 지휘22~25 + 역할30~33 + 교대34~35 + 야영36. 공통 미리보기·중복 발동 방지 뒤 개별 가치 검증을 통과한 것만 다음 단계로 옮긴다. 특히 돌격 칼집의 훈련 중복, 진료 시계의 응답/HPS 교환, 야영의 실제 잔여 기회가 게이트다.
3. 후속36종 =37~72. 경제37~40은 한계수입·가격과 사용처를 재검토하고,52·63·66·71 등은 선행 시스템 없이는 보류한다. 후보 목록에서 삭제하는 것과 실제 풀에 미편입하는 것을 구분한다.
4. 같은 시드·같은 비용의 대조군에서 실제 선택 변화, 미발동/포화/무효 제련, 상속, 저장 멱등성을 확인한다. 단순 문서/산술 검사를 전투 밸런스 통과로 부르지 않는다.

**결론:** 72종을 보존하며 첫 검증25종에 집중한다. 나머지11+36은 조건부 후보이고 36종을 출시 상한이나 확정 목표로 삼지 않는다. 획득 확률·가격·XP·승률 목표·활성화 정책은 추가 검증/승인이 필요한 제안이다. 검토 대응 및 미검증 항목은 [검토 대응표](relic-review-response.md)를 따른다.
