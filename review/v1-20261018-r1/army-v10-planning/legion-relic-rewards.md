# 군단 레벨 유물 3택1 · 3회 우선 trial 명세

2026-10-18 UTC. **설계 + 독립 예산 산술만 완료. 실제 전투 밸런스·제품 구현·배포는 미완료.** 기준은 `IMPLEMENTATION-BASELINE.md`의 v10-trial-p0다. 사용자가 3회안을 우선 설계하는 방향을 재승인하여 `legion-relic-three-trial-1`의 설계 기본값을 아래와 같이 확정한다. 이는 시험 명세의 확정이며 실제 밸런스·지급 구현·제품 통합 승인이 아니다. [구현 기준선](IMPLEMENTATION-BASELINE.md#군단-유물-3회-trial-추가-명세)의 별도 프로필로 연결하며 기존 v10-trial-p0 실행 코드·UI 기본값은 유지한다.

## 1. 결론과 적용 경계

이 trial의 기본값은 한 원정 **3회: 전체 전투 6 / 15 / 27 승리 뒤**, 누적 XP **9 / 23 / 39**다. 첫 빌드 방향을 잡고, 3장에서 보강하고, 4장 후반에 5장 활용을 준비한다. 4회 비교안은 전투20 / XP29를 하나 더 사용한다. 3장에서 두 번 고르게 하므로 유물 수집 느낌은 강하지만 성장·모집 기회를 추가로 압박하고 21전 열쇠 선택과 연속된다. 실제 비교 전 기본값으로 채택하지 않는다.

각 시점의 **기존 혼합 3택1 보상 한 번을 유물 3택1 한 번으로 교체**한다. 기존 보상을 받은 뒤 레벨업 팝업으로 유물을 추가 지급하지 않는다. 모든 경우 전투1~34에서 총34번, 각 최대1개 선택 또는 패스, 35는 정산만 유지한다. 유물 선택의 별도 골드 비용은0G이고, 포기한 성장·모집 선택이 비용이다. 별도의 화면/모달 대신 같은 결과 패널의 보상 종류를 바꾼다.

‘유물 선택 기회 3회’와 ‘유물 3개 획득 보장’은 다르다. 거절할 수 있고, 적격 후보가 부족하면 아래의 고정 패스 슬롯이 나온다. 미래 기능을 가정해 가짜 카드 세 장을 채우지 않는다. 최대3장 중1개이며 보유·효과 상한에 걸린 카드는 제공하지 않는다.

## 2. 표시 레벨과 실제 해금을 분리한다

- Lv.5/6/7을 정원10/11/12로 해석하지 않는다. 보유 상한20, 배치 칸12도 그대로다. 병사 자동 지급·자동 훈련·스탯 증가 없음.
- ‘다음 레벨: 유물 선택 기회, 출전 정원9 유지’처럼 실제 효과를 표시한다. 군단 레벨과 병사 전직/훈련, 각성 자격은 별개다.
- 최종XP50에서 추가 보상 없음. 최종 보스 뒤 사용 불가능한 유물 선택을 만들지 않는다.

## 3. 3장 비중과 열쇠 보장 경로

| 안 | 유물 전용 선택 시점 | 장1/2/3/4/5 횟수 | 3장 비중 | 3장 보스 직전까지 전용 선택 |
|---|---|---|---:|---:|
| 권장3회 | 6 / 15 / 27 | 1 / 0 / 1 / 1 / 0 | 1/3 (33.3%) | 2회 |
| 비교4회 | 6 / 15 / 20 / 27 | 1 / 0 / 2 / 1 / 0 | 2/4 (50%) | 3회 |

여기서 비중은 **유물 전용 기회의 배치 비중**이지 전체 유물 획득 수·확률·공격력 비중이 아니다. 3장 한 번 더 선택하게 하면서 희귀도까지 올리는 이중 상향은 하지 않는다. 모든 장의 희귀도는 기존0.9 함수의 동일 버전 복제를 따른다. 72종 균등·25종 균등 추첨이나 새 전설 확률은 도입하지 않는다.

- 전투21의 기존3슬롯 중 목표 열쇠/비궁극 핵심 유물 **예약1슬롯**은 그대로 유지한다. 같은 보상에서 나머지2슬롯과 함께 최대1개만 고른다. ‘별도 경로’는 별도 지급 횟수라는 뜻이 아니다.
- 전투21에는 군단 레벨 유물 전용 선택을 놓지 않는다. 보스가 열쇠와 유물을 각각 지급하는 이중 예산 금지.
- 3장 전투2 뒤의 방문 선택 상점에서20G 목표 열쇠 구매 대안도 유지한다. 상점 미방문 경로는21전의 예약 슬롯을 쓸 수 있다.
- 전용 열쇠4종은 P0의 목표 획득 경로에 둔다. 이 문서의 유물 전용 랜덤 선택에 편입시켜 열쇠 보장 경로를 대체하지 않는다. 먼저 획득한 목표·지원 기능·자격에 따른21전의 고정 fallback은 기준선대로 유지한다.
- 열쇠가 있어도4장 진입의 명시적 각성 선택/2차 자격/원정 최대1명 조건은 유지한다. 패스하면 자동 각성·후속 보충 지급 없음. 5장 활용, 무궁극 경로 허용도 불변이다.

## 4. 선택 예산과 기회비용

독립 계산기: `legion-relic-budget/model.py`; 결과: `legion-relic-budget/results.json`.

카테고리가 모집/성장/유물1:1:1이고 독립 추첨이라는 **적격성 적용 전 이상적 산술**이다. 34×3=102슬롯 중 성장 예약3(전투2/5/8), 목표 예약1(21)을 빼면 일반 랜덤98슬롯이다. 전용 선택 시점은 이 예약과 겹치지 않는다.

| 원정 지표 | 혼합 기준 | 권장3회 | 비교4회 |
|---|---:|---:|---:|
| 총 선택 횟수 상한 | 34 | 34 | 34 |
| 혼합 / 유물 전용 횟수 | 34 / 0 | 31 / 3 | 30 / 4 |
| 일반 랜덤 슬롯 | 98 | 89 | 86 |
| 유물 카테고리 카드 기대 수, 목표 예약 제외 | 32⅔ | 38⅔ | 40⅔ |
| 성장 카테고리 카드 기대 수, 성장 예약 포함 | 35⅔ | 32⅔ | 31⅔ |
| 모집 카테고리 카드 기대 수 | 32⅔ | 29⅔ | 28⅔ |
| 감소하는 성장/모집 카드 기대 수, 각각 | 0 | 3 / 3 | 4 / 4 |
| 실제 다른 선택의 대체 횟수 가능 범위 | 0 | 0~3 | 0~4 |
| 새 자동 골드 지급 | 0G | 0G | 0G |

혼합3슬롯에 유물 카테고리가 적어도 하나 나올 확률은1−(2/3)^3=19/27≈70.37%다. 이를 전용3슬롯으로 바꾸면 카테고리 제시는100%가 되지만 적격 유물3개·획득·유용성100%가 되는 것은 아니다. 이상적 ‘유물을 하나 이상 볼 기회’ 증가는3회안8/9≈0.889회, 4회안32/27≈1.185회다. 그와 동시에 유물끼리 비교할 폭이 커지므로 실제 힘의 변화는 이 수 하나로 환산할 수 없다.

대신 성장 또는 모집을 적어도 하나 볼 기회를 각각3회안19/9≈2.111회, 4회안76/27≈2.815회 잃는다. 성장/모집 중 어느 것이든 가능한 기회는 각각26/9≈2.889회,104/27≈3.852회 줄어든다. 이 수치는 서로 겹치므로 더하면 안 된다. 실제 플레이어가 성장/모집을 골랐을 횟수는0~3 또는0~4이며 전투 전력과 선택 선호에 따라 달라진다.

골드 산술:
- 직접 수입은 기존 정예0 원정450G/최종 전 사용420G, 장당 정예2면550G/520G 그대로. 34번 전부5G 리롤하면170G로 동일하다. 마일스톤에 추가 무료 리롤을 주지 않는다.
- 전용 선택 때문에 놓친 모집을 전부 상점20G로 대체한다고 가정한 가격 비교 상한은3회안60G,4회안80G다. 전부 훈련30G로 대체한다는 별도 가정의 상한은90G/120G다. **두 상한을 합산하지 않는다.** 실제 판매 여부·방문 기회·자격이 있어야 구매 가능하며 골드만 내면 복구 가능하다고 보장하지 않는다.
- 이 가격 비교는 성장 예약 진화 등을30G에 살 수 있다는 뜻이 아니다. P0 상점 진화 상품은 없고, 성장 종류 전체에 공통 가격을 붙일 수 없다. 성장 예약 전투2/5/8은 보존하지만 그 외 성장 투자 기회 감소는 남는다.
- 4회안은3회안보다 유물 비교 카드 기대값+2, 성장/모집 카테고리 카드 각각−1, 실제 대체 선택 최대+1이며 모집/훈련 대체 가격 비교는 별도로+20G/+30G다.

**34회 고정은 동일 기대가치의 증거가 아니다.** 세 장 모두 유물이면 얻을 확률·선택 품질은 높아지지만 전직·모집 유연성은 낮아진다. 유물 가격·전투력·훈련 가치의 동등성은 주장하지 않는다. 별도 골드 보상·공짜 모집을 추가해 비용을 숨기지 않는다.

## 5. 후보·저장·리롤 계약

첫 검증 레지스트리는 기존17+열쇠4+배치4=25종이다. 계산기는 도감의번호1~21/26~29를 읽는다. ‘레지스트리25’는 ‘실제 획득 가능한25’가 아니다. 기존 해금, 목표 획득처, 구현 capability, 작동 자격을 모두 통과한 ID만 사용한다. 신규8종을 전부 구현 완료로 취급하지 않는다. 조건부11·후속36, 경제37~40, rear_gambit은 활성화하지 않는다.

1. 보상ID는 runId/profileId/승리ID로 고정한다. XP 문턱을 새로 넘은 승리에서 이미 존재하는 보상의 종류만 결정한다. 로드 때 현재 XP만 보고 지난 마일스톤을 새로 지급하지 않는다. 구 프로필 진행 중 자동 이관 없음.
2. 승리 처리 시, 전투 시작에 확정한 편성·기능/해금·보유·상한 상태와 승리 후 반영할 고정 상태를 입력으로 보상 스냅샷을 만든다. **카테고리는 마일스톤/일반 규칙으로 먼저 결정**하며 편성·적격 ID 개수에 따라 바꾸지 않는다. 고정한 희귀도 버전→고정 순서의 적격 ID→사전 fallback으로 내려간다.
3. 시드만 저장하지 않는다. 원 보상과 유료 리롤1회분의 카테고리·희귀도 결과·후보ID/패스·규칙 버전·입력 스냅샷 해시를 결정적으로 생성해 함께 저장한다. 리롤 후보도 같은 고정 스냅샷에서 만들고 아직 노출하지 않는다. 저널·체크섬 검증 후 **저장→재읽기 성공한 경우에만 원 보상 공개**. 노출 전에 실패하면 패널을 열지 않고 같은 거래를 재시도한다.
4. 리롤5G/최대1회는 동일 거래 원장에서 차감·저장→재읽기 성공 뒤 기저장 리롤 후보를 공개한다. 새 난수 추첨 금지. 실패·중복 클릭·재접속에 차감/후보가 달라지면 안 된다. 일반 보상의 성장/목표 예약 슬롯은 리롤에서도 보존한다. 전용 유물 보상은3슬롯 모두 유물이되 같은 희귀도 버전, 리롤 때도 카테고리 전환 없음.
5. 동일 세 장 안의 중복ID, 이미 보유한 ID는 제외한다. 리롤 전후 같은 ID가 다시 나올 수는 있고, 개선을 보장하지 않는다. 먼저 고정된 희귀도 버킷에 다른 후보가 없으면 그 슬롯은 패스다. 비어 있다고 희귀도를 올리거나 다른 카테고리·골드로 바꾸지 않는다.
6. 실효 증가0·작동 불가능한 후보는 제외한다. 현재 출전/지휘 또는 도감이 허용한 공개 도달 조건을 사용하되 첫 유물은 현재 출전에서 작동하는 후보만 둔다. 대가 있는 조건부 교환은 실제 증가·손실을 함께 보이고 순이득이라고 표시하지 않는다. 합산 상한을 넘는 양의 효과를 다른 자원으로 바꾸지 않는다.
7. 적격 후보1/2개이면 나머지는 ‘현재 조건에서 선택 가능한 유물 없음’의0G·0성장 패스 슬롯,0개이면 전체 패스다. 전체 패스라도 카테고리 재추첨·마일스톤 이월·보상 추가는 없다. 다른 편성을 채택하는 정상 전략은 허용하지만 보상 열기/닫기·현재 편성 변경으로 이미 저장된 후보가 바뀌지 않는다.
8. 패널 대기 중 보유·제련 상태를 바꾸는 별도 거래를 막거나 충돌 시 저장된 보상을 유지한 채 선택을 재검증한다. 부적격 선택은 거절하며 새 유물로 바꾸지 않는다. 선택 완료ID를 멱등 저장한다. 최종 정산까지 미선택 후보를 임의 보충하지 않는다.

이 저장 계약은 **아직 런타임 구현/검증되지 않았다.** 아래의 간단한 필터 테스트는 DB 원자성·희귀도 추첨·실제 상한 미리보기 테스트를 대체하지 않는다.
