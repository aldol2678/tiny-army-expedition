# 꼬마 군단 원정대 1.0: 5장 조우·사건 세트

작성: 2026-10-18 UTC  
상태: 로컬 설계안. 제품 코드·저장·빌드·배포 변경 없음. 아래 신규 조우, 행동, 사건 조건, 보상 배치는 **미구현·미검증 제안**이다. 플레이테스트·승률·완주 가능성을 실측한 문서가 아니다.

## 1. 사실과 제안의 경계

- **현행 v0.9는 2장**이다. 1장 바람잎 평원 / 평원의 파수꾼, 2장 잿빛 철성 / 철성의 문지기. 기존 원정은 그대로 2장으로 끝낸다.
- 현행 적 기반은 `raider`, `bow`, `armored`, `swarm`, `brute`, `boss`의 6역할이다. 1장 일반 5·정예 2·보스 1, 2장 일반 4·정예 2·보스 1 조우 정의가 있다. 장별 일괄 HP/피해 배수 대신 구성으로 압박을 달리한다.
- 현행 `v09-content.js`는 `CHAPTERS`, `EVENTS`, `ENCOUNTERS`를 이전 콘텐츠에서 가져온다. 새 5장 정의는 별도 버전으로 만들고 기존 목록에 무조건 추가하지 않는다.
- 현재 사건은 보급 수레·망루·야전 치료소·길잡이 야영지·보급 창고·취사장의 **6종**이다. 아래 8종은 1.0 후보 세트이며 기존 6종 모두와 합쳐 **14종 출시 확정**이라는 뜻이 아니다. `content-plan.md`의 신규 사건 4종 제안보다 상세 후보를 넓힌 것이므로 채택 범위는 별도 결정한다.
- **확정된 원정 구조는 5장, 3장 수집 → 4장 궁극 진입 → 5장 활용**이다. 2차 기본 기술 2개, 3차는 그 2개 유지 + 궁극 1개. 이 문서는 이를 변경하지 않는다.
- 장당 일반/정예6전투 + 보스1의 기본안은 총35전투·34선택 기회·선택 서비스0~10회다. 보스 포함 최소7전투 해석이며 보상 수는 미확정이다. 아래 일반 조우 2종은 작전 슬롯용 풀이고, 정예는 선택한 일반 슬롯을 대체한다. **후보 개수는 실제 전투 횟수가 아니다.** 같은 일반 조우 재등장 시 적 위치·호위 방향만 달리하고 새 보상 창을 더하지 않는다.

### 실제 동작에 맞춘 대응 언어

자동전투 중 플레이어에게 수동 이동·회피·진형 변경·예비 교대를 요구하지 않는다. 배치와 교대는 준비 화면에서 한다. 전투 중 직접 개입은 장착한 지휘 기술 2칸 안의 행동이다. ‘분산’은 시작 배치 제안이며 자동 이동 뒤에도 영원히 흩어진다는 보장이 아니다.

현행 수호 진형은 전군 피해 감소, 응급 회복은 생존자 HP 회복이다. 집중 사격은 **정상 사거리 안** 대상 우선순위이며 벽 뒤 적을 전맵 저격하게 하지 않는다. 사기 고양은 평타 가속이며 주문·치유·궁극을 가속하지 않는다. 현행 강타는 시전 시 위치를 예고하고, 발동 전 시전자 사망 시 취소된다. 즉시 기절·넉백·주문 차단을 전 병사 공통 능력처럼 쓰지 않는다.

## 2. 공통 설계 계약

1. 각 조우는 아래 A/B의 **서로 다른 행동 경로**로 풀 수 있어야 한다. A/B는 검증할 가설이지 이미 통과한 빌드가 아니다. 특정 직업·유물·궁극 보유를 입장 조건으로 검사하지 않는다.
2. 방벽·저격은 유리한 예시일 뿐 필수가 아니다. 지휘 수호, 지원의 치유/보호막, 배치, 접근 중 제거, 공격 후 공백 이용 중 대안을 남긴다. 단발/광역도 특정 클래스명 대신 기능으로 안내한다.
3. 적 신규 행동은 **예고 → 고정 → 실행 → 회복 공백**을 갖는다. 예고 끝까지 표적을 몰래 추적하지 않는다. 시작 때 무경고 강타, 영구 무적, 무한 소환, 치유 무효, 궁극 필수 방어막은 금지한다.
4. 표식·바닥 테두리·아이콘·짧은 문구를 함께 쓴다. 색과 소리만으로 구분하지 않는다. 큰 궁극 연출은 적 예고 아래로 깔고, 모션 감소에서도 고정 범위와 남은 예고를 읽을 수 있게 한다.
5. 수치 대신 행동 조합으로 난도를 올린다. 아래 적 수는 초기 편성 후보이며 HP/DPS·예고 시간·공백·최대 동시 위협은 별도 조율한다. 현재 보스 예고 2.1초·강타병 1.5초를 새 적 전체의 확정 타이밍으로 복사하지 않는다.
6. 4장 첫 조우는 기본 기술을 쓰고 궁극 조건을 관찰할 시간을 준다. 자동/수동 궁극이 아직 미정이므로 ‘정확히 이 순간 버튼을 눌러야 승리’는 설계하지 않는다. 궁극 없는 대응을 같은 조우에서 검증한다.
7. 정예 선택 0회·궁극 0개·예비 0명 경로를 남긴다. 교대는 다음 적 역할과 기존 컨디션 회복을 활용하는 선택이며 매번 교대해야 하는 벌점 시스템이 아니다.

## 3. 실루엣·행동 재료

기존 그림을 재사용해도 새 행동을 구별할 표식이 필요하다. 다음은 제작 지시서이며 **새 이미지가 제작됐다는 뜻이 아니다.**

| 코드 / 재료 | 작은 화면 실루엣 | 예고와 행동 | 대응·금지 |
|---|---|---|---|
| R / 잿빛 보병 `raider` | 짧은 칼, 중간 키 | 기본 접근·근접. 별도 신기술 없음 | 접근 중 제거 / 전열로 받기 |
| S / 빠른 잔병 `swarm` | 낮고 작은 몸, 넓은 간격 | 빠른 접근. 새 순간이동·후열 점프 없음 | 다중 공격 / 여러 전열 접점과 회복 |
| A / 철갑 `armored` | 키보다 넓은 사각 방패 | 전열 유지. 현행 v09 고정 DEF 기반 | 큰 유효 단발 / 지속 공격을 버틸 유지력. 마법이 DEF를 무조건 무시한다고 설명하지 않음 |
| B / 궁수 `bow` | 어깨 위 활의 곡선 | 거리 확보 후 사격. 현행 기본 역할 | 사거리 안 집중 / 전열 유지 후 접근 |
| H / 강타병 `brute` | 넓은 어깨, 들리는 큰 무기 | 원형 예고·고정 위치 강타 | 시전 전후 집중 / 피해 분산·보호·회복 |
| V / 일제궁수, B 파생 | 활 위 세 갈래 깃 | 신규: 사격 준비 중 정지, 좁은 부채 예고 뒤 유한 일제, 이후 재장전 공백 | 준비 중 사거리 안 제거 / 보호 후 공백에 전진. 후열 확정 사망·무제한 관통 금지 |

| 장 보스 / boss 파생 | 큰 몸 + 장별 무기 부속 1개 | 아래 프로필의 명시 순서·공백. HP만 다른 복제 보스로 세지 않음 | 장마다 최소 2해법, 공격 단계마다 피해 가능 |

V·K는 신규 적 역할 2개 후보다. 다른 장은 이를 재조합한다. 구현 범위가 부족하면 신규 적을 더 만들지 말고 경고·재장전·호위 타이밍부터 검증한다.

### 4장 · 깨어난 성채(가칭): 두 기본 기술 위에 궁극을 얹어도 운용이 남는가?

각성 기회는4장 진입 지도 패널이다. 별도 합류 재기회는 없다. 보스를 쓰러뜨려야 궁극을 처음 받는 구조가 아니다.

| 조우 / 구성 후보 | 실루엣·예고·전투 질문 | 해법 A / 해법 B | 보상 대안 |

### 5장 · 마지막 방어선(가칭): 가진 도구를 조합하고 마칠 수 있는가?

새 필수 시스템·전직·적 면역을 가르치지 않는다. 1~4장의 모양·예고 언어를 그대로 사용한다.

| 조우 / 구성 후보 | 실루엣·예고·전투 질문 | 해법 A / 해법 B | 보상 대안 |
|---|---|---|---|

## 5. 사건 후보 8종: 짧은 본문, 선택 두 개

각 사건은 선택을 확정하기 전에 대상·잔액·실제 변화량을 표시한다. `전원`은 보유 병사 전원, 컨디션 회복은 100 상한이며 전투 HP 치유/부활과 다르다. `준비`는 기존 다음 전투 첫 10초 공격 피해 +10%, 중첩 없음. 수치는 기존 사건 교환을 재사용한 초기안이며 새 경제 확정이 아니다.

직업 관련 설명은 활용 예시이지 조건이 아니다. 자격 미달 A는 사유와 함께 비활성, B는 항상 무료로 작동한다. 닫기/뒤로가기는 확정 전 취소이며 제3의 보상 선택이 아니다. 전투를 추가하는 사건은 없다.

### E01 · 두 갈래 망루 / 1장 서비스

본문: “적의 접근로가 보입니다. 더 살필까요, 잠시 쉴까요?”
- A **정찰하기** — “전원 컨디션 −5. 다음 전투 준비.”
- B **그늘에서 쉬기** — “전원 컨디션 +18.”
- 조건: 모두 선택 가능. 준비 보유 시 “준비는 중첩되지 않아요.” 실제 컨디션 변화 0이면 그대로 표시.
- 연결: 전열 유지/돌파/사격 중 어떤 편성을 쓰든 공격 준비와 회복을 비교. 기존 망루의 두 선택을 유지한 짧은 카피.

### E02 · 무너진 훈련장 / 2장 서비스

본문: “훈련장 잔해에 보급품이 남았습니다.”
- A **물자 꺼내기** — “전원 컨디션 −10. 20G 획득.”
- B **그냥 지나가기** — “비용과 보상 없음.”
- 조건: 모두 선택 가능. “컨디션은 0 아래로 내려가지 않아요.” 현행 창고 교환의 재사용이며 특정 직업 노동 보너스 없음.
- 연결: 얻은 골드는 훈련·회복 중 선택해 사용. 이 사건을 거쳐야 2차가 되는 필수 경로는 아니다. 새 훈련 토큰·즉시 무료 훈련을 만들지 않음.

### E03 · 전술 교본 / 2장 또는 4장 연구 서비스

본문: “익숙한 지휘를 다른 방식으로 펼쳐 봅니다.”
- A **변형 연구하기** — “20G. 장착 지휘 1개의 변형을 연구.”
- B **기본형 유지하기** — “비용과 보상 없음.”
- 조건: “20G가 필요해요.” / “연구할 장착 지휘가 없어요.” / “이번 장의 연구 기회를 썼어요.” 해당 사유를 정확히 표시. 2·4장 각 1회, 원정 최대 2회 제안 유지.
- 연결: 집중 처치/충격 차단/압축 표식/돌격 신호 중 장착 기술에 맞는 대상 선택 단계. 병사 기본 기술이나 궁극 연구가 아님. 기본형 복귀는 준비 화면에서 무료, 전투 중 변경 금지.

### E04 · 유물의 흔적 / 3장 전투2 뒤 선택 서비스 후보

본문: “목표 유물의 마지막 단서가 보스에게 이어집니다.”
- A **목표 확인하기** — “목표 효과와 보스 보상 기회를 확인. 비용 없음.”
- B **계속 가기** — “비용과 보상 없이 진행.”
- 조건: 기존 목표가 지정된 원정에 배정. A는 목표 효과·보유 여부·남은 보스 대안을 보여주고 종료하는 정보 선택이다. B도 같은 보스 대안을 유지한다. 목표가 없으면 일반 사건으로 대체.
- 연결: 선택 서비스의 기존 한 자리를 사용하는 정보 사건 후보다. 전투2 뒤 목표 상점과 중복 방문하지 않으며 둘 모두 건너뛸 수 있다. 이미 끝난 일반전 보상에 목표를 소급 추가하거나 다음 일반전 후보를 예약하지 않는다. 정예 목표 슬롯은 전투 보상 안의 별도 후보 경로이지 추가 서비스가 아니다. 열쇠 미획득도 3장 보스에서 기존 한 선택 안의 마지막 대안을 받는다.

### E05 · 유물 보관상 / 3장 전투2 뒤 선택 서비스의 목표 상점 표현

본문: “상인이 찾던 유물을 따로 보관해 두었습니다.”
- A **목표 열쇠 사기** — “20G. 표시된 열쇠 유물 I 획득.”
- B **구매하지 않기** — “비용과 보상 없음.”
- 조건: “20G가 필요해요.” / “이미 가진 유물이에요.” 지정 열쇠와 가격을 확정 전 표시. 이미 보유/부적격이면 표준 상점으로 대체하며 다른 열쇠 무료 지급 없음.
- 연결: 철심/인장/씨앗/등불의 기본 효과와 4장 각성 자격을 함께 표시. **3장에서 즉시 궁극 개방 아님.** 이는 기존 제안된 목표 상점 방문을 두 선택으로 표현한 것이며 별도 추가 사건·서비스·할인 횟수가 아님. 비열쇠 목표는 원래 재고 가격 규칙을 따르고 20G 열쇠 가격을 무조건 적용하지 않음.

### E06 · 깨어나는 제단 / 4장 진입 지도 패널

본문: “쌓아 온 기술 위에 새로운 힘이 깨어납니다.”
- A **한 명 각성하기** — “자격 병사 1명. 기본 기술 2개 유지 + 궁극 1개.”
- B **지금은 안 하기** — “현재 편성을 유지합니다.”
- 조건: “2차 전직과 같은 계열 열쇠 I 이상이 필요해요.” / “이번 원정의 각성을 이미 사용했어요.” 자격 대상 선택 후 미리보기와 확정. 추가 0G·열쇠 비소비·원정 1명은 기존 비교안.

## 6. 보상·경로·저장 연결 규칙

- 3장 목표 정예 슬롯, 보스 최종 대안, 상점 구매는 **동일 유물 보유 상태**를 공유한다. 먼저 획득하면 뒤 고정 슬롯은 생성 시 저장한 같은 예산의 fallback으로 처리하며 추가 보상·새 카테고리 추첨은 없다. fallback 가치/종류는 미확정이다. 리롤·교대·재접속으로 고정 목표를 바꾸거나 복제하지 않는다.
- 목표 슬롯은 예비 포함 보유 전체의 지정 자격을 인정할 수 있지만 일반 후보풀은 기존 적격 규칙을 유지한다. 정보 사건 E04가 예비 전체를 일반 드롭풀에 넣거나 목표 슬롯을 추가하는 우회로가 아니다.
- 유물/병력 대안은 그 전투 창의 카테고리 일정에 맞춘다. 병력 전용 창에 위 조우표의 일반 설명만 보고 유물 탭을 새로 추가하지 않는다.
- 2차 기술을 완성하는 성장 슬롯을 E02 현금이나 E03 연구에 종속시키지 않는다. 3장 유물은 4장 부모 기술 유지 덕분에 계속 작동해야 한다.
- 이벤트 결과는 표시 → 현재 자격/잔액 재검증 → 한 번 반영 → 저장. 예약·지출·획득·각성의 중간 상태 저장으로 재접속 이득을 만들지 않는다. 저장 실패 시 성공 메시지를 먼저 표시하지 않는다.
- ‘지금은 안 하기’, 무효 후보, 자금 부족, 목표를 다른 후보 대신 거절한 상태를 구분한다. 사용자 선택을 무상 보정하지 않는다.
